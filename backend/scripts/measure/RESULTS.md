## 라벨 정확율 종합 (카피 제외 — other 인스턴스만, 실험5·6)

카피(headline/body/cta)는 전 케이스 100%(PIL 합성)라 **라벨(other)이 유일한 변별 지표**다. 아래는 카피를 뺀 라벨 인스턴스만의 exact 비율.

**사람검수 (엄격 — 원본 라벨과 대조):**

| 모델 | 라벨 정확율 |
|---|---|
| gemini-2.5 (R003) | 68.8% (44/64) |
| gemini-3-pro (R007) | **86.0%** (86/100) ↑ |
| gpt-image-1 (R004) | 24.1% (32/133) |
| gpt-image-2 (R008) | **19.8%** (32/162) ↓ |

**VLM (관대 — 읽히면 exact):**

| 모델 | 라벨 정확율 |
|---|---|
| gemini-2.5 (R001) | 100% (69/69) |
| gemini-3-pro (R005) | 100% (94/94) |
| gpt-image-1 (R002) | 72.9% (105/144) |
| gpt-image-2 (R006) | 86.0% (153/178) |

**핵심** — 사람검수 기준 gemini가 openai를 압도(86.0% vs 19.8%, ~4.3배). 티어 상승은 **gemini만 개선**(68.8→86.0%), **openai는 악화**(24.1→19.8%). 같은 gpt-image-2를 VLM은 86%·사람은 19.8%로 봐(≈4배 차) 판정기 간극이 openai에서 특히 크다 — fine-print 라벨이 "읽히지만 원본과 다른" 경우가 많기 때문.

## 판정 기준 정의 (모든 기록 공통)

- **결함** = `exact`(정확) 외 전부 = `typo`(오탈자)·`broken`(깨짐)·`cut`(잘림)·`missing`(누락).
- **카피** = `element` in headline/body/cta = **코드(PIL)가 얹은 텍스트**. **라벨(기타)** = `element=other` = **AI가 그린 이미지 속 텍스트**(상품 라벨·성분표·배경 문구·헛것).
- **무결점 이미지 비율**(대표 수치) = 텍스트 인스턴스가 하나도 결함이 아닌 이미지 / 전체 이미지. **이미지 단위, 쪼개기에 불변.**
- **전체 결함율** = 결함 인스턴스 / 전체 텍스트 인스턴스(카피 3칸 + 기타). **텍스트 단위, 쪼개기에 민감.**
- **기타 셈 규칙(A)** — 시각적으로 구분되는 텍스트 블록 1개 = 1인스턴스. 정상 렌더도 exact로 기록.
