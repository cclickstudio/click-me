# 세대별 브랜드 인지도 — 실데이터 주입 전략 (Tier 3)

> [PERSONA_COHORT_KNOWLEDGE_STRATEGY.md](./PERSONA_COHORT_KNOWLEDGE_STRATEGY.md) §4.2의 **Tier 3(실데이터 주입)** 을 깊게 푼 메모.
> 결론: **Tier 3은 새 메커니즘이 아니라 Tier 2의 '사실' 출처를 LLM 추정 → 실측 인지도 데이터로 바꾸는 업그레이드다.
> 브랜드별·세대별 인지도 실측표를 해석 단계에서 1회 룩업해 공유 사실로 주입하고, 친숙/낯섦은 그대로 나이가 판단한다.
> 데이터 커버리지·라이선스가 본 게이트라 클라이언트가 브랜드 단위 정확도를 요구할 때 착수하는 Phase 2 과제다.** (작성일: 2026-06-19)

> 선행: Tier 1 = 형성기 게이팅·말투(프롬프트) · Tier 2 = 브랜드 시대성 1회 추출·공유(`structured_analysis.brand_era`).
> Tier 3은 이 둘의 **데이터 충실도**를 한 단계 올린다.

---

## 0. TL;DR

1. **Tier 2의 한계** — 브랜드 전성기·세대 친숙도를 **LLM의 얼어붙은 추정**으로 채운다. 유명 브랜드는 그럭저럭 맞지만,
   무명·신생·지역 브랜드나 미묘한 세대 격차에선 틀리거나 환각한다(같은 결의 시대착오가 *사실* 층위에서 남음).
2. **Tier 3의 정체** — 그 '사실'을 **실측 인지도 데이터**(한국갤럽 브랜드 트래킹 등 브랜드×연령 인지율)로 교체한다.
   메커니즘(해석 1회 추출 → 공유 주입 → 나이가 친숙도 판단)은 Tier 2와 동일. **출처만 LLM → 실측.**
3. **주입 지점** — 페르소나마다 검색하지 않는다. `interpret_ad`가 브랜드를 식별하면 인지도 실측표를 룩업해
   `structured_analysis.brand_era.awareness_by_age`로 붙인다. 반응 프롬프트는 **페르소나 본인 연령대의 실측 인지율**만 본다.
4. **게이트** — 코드가 아니라 **데이터**다. 브랜드 단위 인지율표 확보(라이선스·커버리지)가 비싸고 어렵다. 미수록 브랜드는
   Tier 2(LLM 추정)로 **graceful fallback**. 그래서 Phase 2, 그것도 클라이언트가 브랜드 정확도를 요구할 때만.

---

## 1. 왜 Tier 3인가 — Tier 2가 남기는 갭

Tier 2는 브랜드 시대성을 **공유 사실**로 1회 추출해 "사실은 공유, 다양성은 나이"라는 가드레일을 지켰다. 그러나 그 *사실*의
출처가 LLM의 파라메트릭 지식이라, [PERSONA_COHORT_KNOWLEDGE_STRATEGY.md](./PERSONA_COHORT_KNOWLEDGE_STRATEGY.md) §2가
경고한 문제가 **한 층 위로 옮겨갈** 뿐 완전히 사라지진 않는다.

| 구간 | Tier 2(LLM 추정) | 실제 필요 |
|---|---|---|
| 유명 전국 브랜드(칠성사이다 등) | 대체로 맞음 | 그대로 충분 |
| 신생·무명·D2C 브랜드 | 재료 없음 → `identified=false`(미주입) 또는 환각 | 실측 인지율 |
| 세대 격차가 미묘한 브랜드 | "older/younger" 거친 분류만 | **연령대별 인지율 곡선**(20대 81% vs 60대 32% 식) |
| 지역·서브컬처 브랜드 | 거의 모름 | 세분 실측 |

→ Tier 3은 이 "재료 없음/거침" 칸을 **숫자로 채운다.** 단, 모든 칸을 채우려 들지 않는다 — 채울 수 있는 브랜드만 채우고
나머지는 Tier 2로 떨어뜨린다(원칙 3 "데이터 없는 건 데이터 없다고").

## 2. 무엇을 주입하나 — 데이터 형태

브랜드를 키로, **연령대별 인지율(awareness rate)** 을 값으로 갖는 실측표 한 장.

```jsonc
// data/simulation/brand_awareness.json (예시 스키마)
{
  "source": "gallup-brand-tracking-2026Q1",   // 출처·버전 (재현성)
  "as_of": "2026-03",
  "brands": {
    "칠성사이다": {
      "aided_awareness_by_age": {              // 보조 인지(brand 보여주고 "아세요?")
        "10-19": 0.74, "20-29": 0.81, "30-39": 0.88,
        "40-49": 0.93, "50-59": 0.95, "60-69": 0.96
      },
      "skew": "all",
      "note": "전세대 국민 음료"
    }
  }
}
```

- **인지도 유형 구분** — 보조 인지(aided)와 비보조 인지(unaided/top-of-mind)는 다르다. 광고 반응엔 "이 브랜드를 아는가"가
  핵심이라 **보조 인지율**이 1순위. 가능하면 둘 다 보관.
- **연령대 밴드**는 페르소나 샘플러·KISDI와 동일 밴드(10-19/20-29/…)로 맞춘다(룩업 정합).
- 표는 **브랜드 단위로 듬성듬성** 차도 된다 — 있는 브랜드만 Tier 3, 없으면 Tier 2.

## 3. 데이터 출처 후보 (현실 점검)

| 출처 | 제공 | 강점 | 발목 |
|---|---|---|---|
| **한국갤럽 브랜드 트래킹** | 브랜드×인구통계 인지·선호·사용 정기 추적 | 권위·연령 교차·정기성 | **유료·계약, 상업적 활용 범위 별도 확인** |
| **대학내일20대연구소** | 세대별 소비·브랜드 선호(2030 중심) | 세대 결 살아있음 | 브랜드 단위 인지율은 제한적, 일부 유료 |
| **소비자원·언론진흥재단·오픈서베이** | 카테고리/이슈성 인지 조사 | 일부 공개 | 브랜드 포괄성 낮음, 비정기 |
| **자체 설문(서베이몽키/오픈서베이 패널)** | 필요 브랜드만 즉석 측정 | 커버리지 통제 가능 | 비용·표본·반복성 |
| **메타/구글 트렌드·검색량 프록시** | 무료, 시계열 | 보조 신호로 저렴 | 인지율이 아니라 관심도 — **인지도 대용 금지, 보조만** |

> 핵심 제약은 **브랜드 단위 포괄 수집의 비용·라이선스**다([PERSONA_GENERATION_STRATEGY](./Persona/PERSONA_GENERATION_STRATEGY%20(1).md)
> §7.5 라이선스 메모와 정합 — 민간 자료의 상업적 활용 범위는 서비스화 단계에서 확인 필요). 그래서 Tier 3은 "전 브랜드 일괄"이
> 아니라 **클라이언트 캠페인의 그 브랜드만 핀포인트로** 확보하는 게 현실적이다.

## 4. 주입 메커니즘 — Tier 2 위에 얹는다

페르소나별 검색은 금지(가드레일 §5-1) — 사실은 해석 단계에서 1회만 룩업한다.

```
interpret_ad (해석 1회)
  └ 브랜드 식별(perceived_brand / brand_era.identified)
      └ brand_awareness.json 룩업(있으면)
          → structured_analysis.brand_era.awareness_by_age = {연령대: 인지율}  (실측)
          → awareness_source = "gallup-...-2026Q1"
  └ 미수록·미식별 → Tier 2(LLM 추정 era/note) 그대로  ← graceful fallback

react ×N (페르소나별)
  └ _brand_era_lines: awareness_by_age 있으면 → 내 연령대 값만 1줄 주입
      "이 브랜드 내 또래(20대) 인지도 약 81%(실측). 낯설면 낯선 대로 반응."
  └ 없으면 → Tier 2 텍스트(전성기·note) 그대로
```

- **다양성은 여전히 나이에서.** 실측표는 전원 공유 사실이고, **페르소나는 자기 연령대 칸만** 본다 → 같은 표를 나이로 다르게
  읽는다(20대는 81%, 60대는 32%). 표를 통째로 주지 않아 "정답 유도"·동질화를 피한다.
- **스키마 무변경.** `awareness_by_age`는 `structured_analysis`(JSONB) 안에 들어가므로 Tier 2와 똑같이 계약·ORM·Alembic
  변경이 없다(`visual_elements`·`brand_era`와 동일 패턴).
- **새 순수 도구 1개** — `tools/brand_awareness/`(룩업·밴드 정규화, LLM✗). 어댑터·노드는 안 바뀌고 `interpret_ad` 내부에서 호출.

## 5. 구현 스케치 (Phase 2 착수 시)

1. `data/simulation/brand_awareness.json` — 확보한 브랜드만. `source`·`as_of` 필수(재현성).
2. `tools/brand_awareness/lookup.py` — `lookup(brand_name) -> dict | None`. 브랜드명 정규화(공백·영문/한글 표기·별칭) + 연령 밴드 매핑.
3. `ad_interpreter.py` — 브랜드 식별 후 룩업해 `brand_era.awareness_by_age`·`awareness_source` 부착(있을 때만).
4. `reaction.py:_brand_era_lines` — `awareness_by_age[persona_band]` 있으면 그 값으로 1줄, 없으면 현행 Tier 2 텍스트.
5. 집계(선택) — `brand_recognition_rate`(마이그 010, 시뮬 결과의 *가상* 식별률)와 **실측 인지율**을 보고서에서 나란히 표시하면
   "우리 페르소나가 실제 인지도와 얼마나 정합한가"를 캘리브레이션 신호로 쓸 수 있다(REPORT §2-5 연계, 단언 아닌 비교).

## 6. 가드레일

1. **페르소나별 검색·룩업 금지.** 룩업은 해석 단계 1회. 페르소나는 공유된 표의 자기 칸만 읽는다(재현성·일관성).
2. **사실은 공유, 다양성은 나이.** Tier 2와 동일. 실측표가 정밀해져도 이 원칙은 안 바뀐다.
3. **없으면 없다고 — Tier 2로 fallback, 절대 날조 금지.** 미수록 브랜드에 인지율을 지어내지 않는다(원칙 3).
4. **인지도 ≠ 관심도.** 검색량·트렌드는 인지율 대용으로 쓰지 않는다(보조 신호로만, 출처 명시).
5. **재현성.** `awareness_source`·`as_of`를 패널/엔진 버전과 함께 기록. 데이터 갱신 시 버전 올림.
6. **라이선스.** 상용 데이터(갤럽 등)의 상업적 활용 범위를 서비스화 전 확인. 평문 로그에 원본 마이크로데이터를 남기지 않는다.

## 7. 합격 기준 / 검증

- **실측 대조** — Tier 3 주입 브랜드에서, 시뮬레이션 `brand_recognition_rate`(연령대별)가 실측 인지율 곡선과 **방향 일치**
  (20대>60대 식). 수치 정밀 일치가 아니라 방향(원칙 4).
- **세대 정합성 A/B** — Tier 2(LLM 추정)만 vs Tier 3(실측) 두 모드로 같은 무명 브랜드 광고를 돌려 utterance 친숙도 차이를 육안 확인.
- **분산 보존** — aggregator `variance_warning`/`effective_n`으로 실측 주입이 세그먼트 차이를 죽이지 않는지 확인.
- **fallback 안전** — 미수록 브랜드가 Tier 2로 매끄럽게 떨어지고 에러·빈칸이 안 나는지.

---

## 8. 트리거 · 비용 · 일정

- **트리거** — 클라이언트가 **브랜드 단위 인지도 정확도**를 요구하거나, 브랜드 헤리티지/인지 전제 캠페인을 테스트할 때.
- **비용 게이트** — 코드는 가볍다(룩업 도구 1개·JSON 1장). 진짜 비용은 **인지율 데이터 확보**(라이선스·자체 설문)다.
- **일정** — 발표(7/14) 범위 밖 **Phase 2**. 우선은 그 캠페인의 핵심 브랜드 1~소수만 핀포인트 확보로 시작, 포괄 수집은 그 다음.

---

## 9. 한 문장 요약

**Tier 3은 Tier 2의 '브랜드 시대성'을 LLM 추정에서 실측 세대별 인지율로 바꾸는 업그레이드다 — 해석 단계에서 인지율표를
1회 룩업해 공유 사실로 주입하고 페르소나는 자기 연령대 칸만 읽으며, 표에 없는 브랜드는 Tier 2로 떨어뜨린다. 메커니즘이 아니라
데이터 확보(라이선스·커버리지)가 게이트라 브랜드 정확도가 필요할 때 착수하는 Phase 2다.**
