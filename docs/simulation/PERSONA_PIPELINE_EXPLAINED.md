# 페르소나는 어떻게 만들어지나 — 데이터부터 LLM 프롬프트까지

> 인구통계·성격·한국 정서 데이터로 페르소나를 만들고, LLM에게 무엇을 어떻게 넘기는지 코드 기준으로 세세히 설명한다.
> 핵심 한 줄: **다양성은 "통계 데이터 샘플링"이 강제하고, LLM은 맨 마지막 두 단계(서사·반응)에서만 등장한다.**

---

## 0. 큰 그림 — 6단계 조립 라인

페르소나 1명은 아래 순서로 만들어진다. **단계 1~3은 LLM을 전혀 쓰지 않는다**(순수 통계 샘플링). LLM은 4-a, 4-b에서만.

```
[단계1]        [단계2-α]      [단계2-β]       [단계3]        [4-a]          [4-b]
인구통계   →   성격(OCEAN) →  미디어 행동  →  소비가치   →   인물 서사  →   광고 반응
나이·성별·지역  5유형 샘플링    노출맥락       한국 정서       (LLM 1회)      (LLM, 광고마다)
   │              │              │              │
   └──────── 통계 분포 샘플링 (LLM 없음, 결정적 seed) ────────┘
   = 여기서 이미 "서로 다른 1,000명"이 확정된다. LLM은 이걸 말로 풀 뿐.
```

- **왜 이렇게?** LLM에게 "30대 여성 만들어줘"라고 시키면 학습 데이터 평균으로 수렴해 1,000명이 다 비슷해진다(동질화). 그래서 속성은 전부 **실제 한국 통계 분포**에서 뽑는다.
- 단계 1~3 결과는 `Persona` 객체 한 개로 합쳐진다(아래 §7).
- 코드 위치: 단계1~3 = `tools/sampling/persona_sampler.py`, 데이터 로딩 = `data/simulation/loader.py`, 서사 = `adapters/gemini_narrator.py`, 반응 = `adapters/gemini/reaction.py`.

## 1. 단계1 — 인구통계 뼈대 (나이·성별·지역)

**데이터** (`data/simulation/distributions/` + `raw/population_age_sex.csv`)

- 행안부 주민등록 원본 → 연령밴드별 `share`(인구 비중)·`male_ratio`(남성 비율)·`region_weights`(시도 분포).

**샘플링 로직** (`_population_cells` → `_build_persona`)

1. 연령밴드 × 성별로 "셀"을 만든다. 각 셀의 가중치 `w = 밴드비중 × 성비`.
2. **메타 도달성 보정(`reachability_sampling=True`, 현재 기본 ON)**: `w × 그 연령대의 메타(인스타/페북) 침투율`(`meta_reach.json`, §Tier2). → 젊은 연령일수록 침투율이 높아 표본이 자동으로 젊게 쏠린다(20대 0.88 vs 60대 0.10). 지역은 보정 안 함(§9 참고).
3. 배분 방식(`allocation`):
  - `proportional`(기본): **쿼터(정수 비례 배분, 최대잔여법)** — 셀별 인원을 인구×도달 비율로 미리 확정. 독립 추첨이 아니므로 작은 표본에서도 연령·성별 구성이 안정(인구 20% → 표본 ~20%). 가중치 `weight=1.0`(self-weighting). *(2026-06-16: 독립 추첨 → 쿼터로 변경)*
  - `stratified`: 얇은 층에 최소 표본(floor)을 보장하고, 과대표집한 만큼 `weight`로 되돌림 → 집합은 평탄, 모집단은 가중으로 대표.
4. 확정된 셀 안에서 **나이는 밴드 범위 내 균등 추출**(예: 20-29 셀이면 20~29 중 랜덤), **지역은 `region_weights`로 가중 추출**.

> ⚠️ 결과를 볼 때 헷갈리기 쉬운 점:
> - **도달성 보정 효과는 "중간 정도"다.** 20대를 인구 대비 약 2배(13%→28%)로 끌어올리지만, 40~60대도 비중이 크게 남는다(아래 §8 표). "20대 압도·중장년 소멸"이 아니다.
> - **연령·성별 셀 구성은 쿼터라 작은 표본에서도 안정**(반올림 오차만). 단 **셀 안의 정확한 나이·지역·OCEAN·소비가치는 여전히 랜덤**이라 그 세부 분포는 표본이 작으면 출렁인다.
> - `stratified`는 전 연령이 더 고르게 보이는데, floor 때문이고 도달 쏠림은 `weight`에 들어간다.

## 2. 단계2-α — 성격 (OCEAN 빅5)

**데이터** (`ocean_age_bands.json`) — 서울대-카카오 OCEAN(N=81만, Nature 논문)

- 한국인을 5개 성격 유형으로 군집: `Average`, `Introverted-Open`, `Introverted-Reactive`, `Expressive`, `Conventional`.
- `type_proportions`(전체 비율): 예) Average 47.3%, Introverted-Open 14.8%, …
- `type_profiles`(유형별 5차원 mean·sd) — **표준화 factor score**(0이 평균, 양수=평균 이상):
  - 예) `Expressive`: 외향성 mean **1.33**, 개방성 1.03 (외향·개방이 매우 높은 유형)
  - 예) `Average`: 전 차원 0 근처 (평범한 유형)

**샘플링 로직** (`_sample_ocean`)

1. `type_proportions` 비율로 5유형 중 하나를 뽑는다.
2. 그 유형의 차원별 `mean·sd`로 **정규분포 샘플링**(`gauss`), `[-5, 5]`로 클립.
3. 결과는 5개 점수 dict. 예: `{"openness": 0.83, "extraversion": 1.41, "neuroticism": -0.30, ...}`

> ⚠️ OCEAN은 0~~100 점수가 아니라 **표준화 점수(평균 0 기준 ±)** 다. 결과에서 음수가 나오는 게 정상.
> 신뢰도 차등: 20~~30대는 표본이 두꺼워 `P1`(정식), 40대+는 `P2`(표본 적음, 보수적).

## 3. 단계2-β — 미디어 행동 (노출 맥락)

**데이터** (`media_behavior.json`) — KISDI 한국미디어패널 2024, 연령×성별 셀

- `device_minutes`: 기기별 하루 사용 분(예 20대 여성 — PC 179분, 스마트폰 171분, TV 81분…)
- `daily_media_minutes`: 하루 총 미디어 시간(mean/sd)
- `exposure`: 시간대×매체×행위×장소별 노출 확률 후보(예 `{오후, PC, 문서/그래픽작업, 직장, p:0.24}`)

**샘플링 로직** (`_sample_media`)

1. `primary_medium`(주 이용 기기): `device_minutes`로 가중 추출.
2. `daily_media_minutes`: 정규분포로 분 수 생성.
3. `exposure_candidates`: **소셜피드(SNS·동영상 @ 스마트폰/PC) 맥락만** 추려 상위 5개 — *메타 전용이므로 TV·신문은 제외*(2026-06-16 수정).
4. `meta_reach`: 단계1 가중에 쓰인 메타 침투율(투명성 기록). `social_feed_reach`(KISDI 영상 비중)는 참고치로만 기록(가중에는 더 이상 안 씀, §9).

> 이 노출 후보는 단계 4-b(반응)에서 `exposure_context`("이 광고를 어디서 봤나")로 하나 선택된다. 메타 광고이므로 항상 소셜피드.

## 4. 단계3 — 한국 정서 (소비가치)

**데이터** (`consumption_values.json`) — 대학내일20대연구소 등 응답률

- `values`(공통): `성능 0.876`, `품질 0.808`, `편의 0.716` (그 가치를 중시하는 사람 비율)
- `generation_specific.Z세대`: `저렴한 가격 0.76`, `취향·덕질 0.743`

**샘플링 로직** (`_sample_consumption`)

- 각 가치마다 `random() < 응답률`이면 **보유(True)**, 아니면 False. (예: 성능은 87.6% 확률로 보유)
- **29세 이하**면 Z세대 전용 가치를 추가로 합쳐서 판정.
- 결과: `{"성능": true, "품질": true, "편의": false, "저렴한 가격": true, ...}`

### 단계1 확장 — 사회경제 (소득·학력)

**데이터** (`socioeconomic.json`) — KISDI 연령×성별 셀

- `income`(8구간 share), `education`(6단계 share). 예) 20대 여성 — 소득없음 32%, 300~400만원 32% / 학력 대학교 88%.
- `_sample_socioeconomic`: 각각 share로 가중 추출 → `{"income_bracket": "300~400만원", "education": "대학교"}`

## 5. 4-a — 인물 서사 생성 (LLM 최초 등장)

여기서 **처음으로 LLM**을 쓴다. 단계 1~3에서 만든 속성 묶음을 한국어 인물 소개로 "풀어주는" 역할만 한다. **패널 빌드 시 1회**만 호출하고 캐시한다(시뮬레이션마다 재생성 안 함).

**코드** `adapters/gemini_narrator.py` (모델 `gemini-2.5-flash`)

**실제로 LLM에 넘어가는 프롬프트:**

```
다음은 통계적으로 샘플링된 한국 소비자 한 명의 속성이다. 이 속성들을 자연스러운
한국어 인물 소개 2~3문장으로 풀어라. **주어진 속성만 사용**하고, 새로운 나이·성별·
직업·소비 성향을 지어내지 마라.

- 나이: 27
- 성별: F
- 지역: 서울
- OCEAN(표준화 점수, 양수=평균이상/음수=평균이하): {'openness': 0.83, 'extraversion': 1.41, ...}
- 미디어 행동: {'primary_medium': 'PC', 'daily_media_minutes': 320, ...}
- 보유 소비가치: ['성능', '품질', '저렴한 가격', '취향·덕질']
```

**핵심 규칙** — 프롬프트가 "주어진 속성만 사용, 새 속성 생성 금지"를 강제한다. LLM이 나이·직업을 임의로 지어내면 단계 1~3이 강제한 다양성이 깨지기 때문(동질화 방지).

## 6. 4-b — 광고 반응 생성 (LLM, 광고마다 새로)

캐시된 페르소나 + 광고 + 노출 맥락을 LLM에 주고 "이 사람처럼" 광고에 반응시킨다. **광고마다 매번 호출**하며 캐시하지 않는다. 출력은 집계 가능한 **구조화 JSON(§3.5 스키마)** 으로 강제한다.

**코드** `adapters/gemini/reaction.py` (`temperature=1.0`로 응답 다양성 보존)

**실제로 LLM에 넘어가는 프롬프트(요약):**

```
당신은 아래 한국 소비자 '본인'입니다. 이 사람의 성격·형편·미디어 습관에 충실하게,
주어진 광고에 솔직하게 반응하세요. 교과서적 정답이 아니라 이 사람의 실제 반응을.

[나]
- 27세 F, 서울
- 학력 대학교, 월소득 300~400만원
- OCEAN(표준화, 양수=평균이상): {'openness': 0.83, 'extraversion': 1.41, ...}
- 주 이용 미디어: PC
- 중시 소비가치: ['성능', '품질', '저렴한 가격']
- 서사: (4-a에서 생성된 인물 소개)
- 지금 노출 맥락: 저녁·집·스마트폰/휴대폰·SNS
[내 세대]                                           # ← Tier 1 (나이로 형성기·말투 게이팅)
- 브랜드·문화 취향이 형성된 시기는 대략 2014~2024년입니다.   # birth_year = 현재연도 − age
- '내 세대에 익숙한지'를 나이에 비추어 판단, 모르는 브랜드는 아는 척 말고 낯섦 반영.
- utterance는 내 나이대가 실제 쓰는 말투·어휘·어미로(유행어 남발 금지).

[광고]
- 업종: beverage
- 메시지: 신제품 출시
- 추정 타깃: 20대1
- 가격: 정가 30,000원 → 할인가 19,900원 (내 월소득 기준으로 비싼지/적당한지 판단)
- 브랜드 시대성(전원 공유 사실): … (친숙/낯섦은 내 형성기로 판단)   # ← Tier 2 (식별된 유명 브랜드만)
[광고 비주얼]                                        # ← §4-a 공유 시각 인벤토리(있을 때)
- 첫눈에 띄는 것 / 주요 시각요소 / 색감·톤

[출력 — 아래 JSON만]
{ "aisas": {...}, "drop_stage": ..., "purchase_intent": 1~5, "trust": 1~5,
  "rejected": bool, "emotion_tag": [정해진 enum 중],
  "brand_recognized": bool, "perceived_brand": "...",       # 브랜드 식별(§2-5, DB 영속)
  "noticed_first": "가장 먼저 눈에 들어온 요소",              # §4-b salience(탐색적, DB 미영속)
  "utterance": "한 문장 솔직한 반응" ... }
```

**프롬프트 설계 포인트**

- LLM을 "본인"으로 몰입시킨다("당신은 이 소비자 본인입니다").
- 숫자(구매의도·신뢰도)와 태그(감정·거부사유)는 **정해진 값(enum)으로만** 출력하게 강제 → 집계 엔진이 코드로 합산 가능(자유 텍스트 금지).
- 호출은 `response_mime_type: application/json`으로 JSON만 받는다(`adapters/gemini/_common.py`).
- 가격은 "내 월소득 기준으로 판단"처럼 **공식 없이** LLM이 적합도를 판단하게 둔다.
- **세대 게이팅·말투(Tier 1)** — `_generation_lines(age)`가 형성기(15~25세)를 계산해 브랜드 친숙도·어투를 나이로 조건화. 시대착오("출생 전 브랜드 추억")를 막는다.
- **브랜드 시대성 공유(Tier 2)** — `interpret_ad`가 `structured_analysis.brand_era`로 브랜드 전성기·세대 친숙도를 **1회** 추출해 전원에 동일 주입. 사실은 공유, 친숙/낯섦은 나이가 판단(`_brand_era_lines`). 무명·텍스트 광고면 미주입. 둘 다 PERSONA_COHORT_KNOWLEDGE_STRATEGY 참조.

> **숫자는 코드, 문장만 LLM.** KPI(클릭의향률·구매의도 평균·CI)는 LLM이 만든 게 아니라, 이 JSON들을 집계 엔진(`tools/aggregation`)이 코드로 가중 평균·부트스트랩한 결과다.

## 7. 완성된 페르소나 1명 (Persona 객체)

단계 1~3(+4-a 서사)이 합쳐진 최종 형태 (`contracts/schemas.py:Persona`):

```jsonc
{
  "persona_id": "P-00042",
  "age": 27,                    // 단계1 (밴드 내 균등)
  "gender": "F",                // 단계1
  "region": "서울",             // 단계1 (region_weights)
  "ocean": {                    // 단계2-α (5유형 → mean·sd 샘플)
    "openness": 0.83, "conscientiousness": 0.12,
    "extraversion": 1.41, "agreeableness": -0.05, "neuroticism": -0.30
  },
  "media_behavior": {           // 단계2-β
    "primary_medium": "PC", "daily_media_minutes": 320,
    "exposure_candidates": [ {timeband, medium, activity, place} ... ],  // 소셜피드만
    "social_feed_reach": 0.1446
  },
  "consumption_values": {       // 단계3 (한국 정서)
    "성능": true, "품질": true, "편의": false, "저렴한 가격": true, "취향·덕질": true
  },
  "socioeconomic": {            // 단계1 확장
    "income_bracket": "300~400만원", "education": "대학교"
  },
  "weight": 1.0,                // 표본 가중치(proportional이면 1.0)
  "profile_narrative": "..."    // 4-a LLM 서사
}
```

## 8. 결과가 기대와 다르게 보일 때 — 자주 헷갈리는 점


| 관찰                           | 이유                                                        |
| ---------------------------- | --------------------------------------------------------- |
| 화면에서 20대가 그렇게 많아 보이지 않는다 | **정상.** 도달성 보정은 20대를 인구 대비 약 2배(13%→28%)로 올릴 뿐, 40~60대도 비중이 크다. 20대는 "단일 최다 밴드"지 "과반"이 아니다. |
| 표본이 작아도 연령·성별 비율은 일정하다 | **정상(2026-06-16~).** `proportional`이 쿼터 방식이라 인구 20% → 표본에서도 ~20% 고정(반올림 오차만). |
| 그런데 셀 안 나이·OCEAN·지역은 표본 작으면 출렁인다 | 셀(연령×성별)만 쿼터로 고정되고, 그 안의 세부 속성은 여전히 랜덤 추첨이라 작은 표본에선 노이즈가 남는다. |
| `stratified`인데 전 연령이 고르게 나온다 | floor로 얇은 층을 보장하기 때문. 도달 쏠림은 `weight`에 들어가 가중 KPI에 반영됨. |
| OCEAN 값에 음수가 있다              | 0~100이 아니라 **표준화 factor score**(평균 0 기준). 음수=평균 이하.       |
| 서사가 비어 있다                    | mock 모드이거나 고정 패널 미빌드. 실 Gemini + 빌드 시 채워짐.                |
| 같은 설정인데 페르소나가 매번 똑같다         | `seed` 고정으로 **결정적**이기 때문(재현성·A/B 비교용). seed를 바꿔야 달라짐.     |
| 노출맥락에 TV가 안 보인다              | 메타 전용이라 소셜피드만 선택하도록 막아둠(2026-06-16 수정).                   |

**도달성 ON 목표 추출 비율(노이즈 없는 이론값):**

| 모드 | 10대 | 20대 | 30대 | 40대 | 50대 | 60대 | 70+ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 도달성 OFF(순수 인구) | 6% | 13% | 15% | 17% | 18% | 16% | 16% |
| 도달성 ON(메타 침투율, Tier 2) | 12% | **26%** | **25%** | 19% | 13% | 4% | 1% |

> Tier 2(메타 침투율) 적용 후 **20~30대 합 51%**, 50대+ 급감(60대 4%·70+ 1%). 메타 audience를 제대로 반영한다. *(이전 Tier 1 프록시에서는 30대가 15%로 과소·50~60대가 과대였음 — §9 참고.)* **표본 ~300명 이상**이어야 이 비율이 안정적으로 보인다.

## 9. 알려진 한계 & 고도화 영역 (Tier 2)

현재 메타 접근성(reach) 모델은 **Tier 1**(일반 소셜 프록시)이라 다음 한계가 있다. 발표 후 고도화 대상.

### (1) reach 출처 — 메타 침투율 곡선으로 전환 완료 ✅ (2026-06-16, Tier 2)
**문제(과거 Tier 1):** 소셜 판정이 `{"SNS", "동영상/개인방송"} @ 스마트폰/PC`였는데, **KISDI 다이어리에서 "SNS" 라벨이 거의 비어 있어(노출확률 합 0.02)** reach ≈ "동영상/개인방송(유튜브)" 시청 비중만 쟀다. 피드 스크롤에 가까운 **"커뮤니케이션"(카톡·SNS, 1.12)은 제외**돼, reach가 "메타 사용"이 아니라 "유튜브 시청" 패턴이 됐다(예: 30대 reach 0.068 < 40대 0.073 — 비현실적).

| 행위 라벨 | 노출 합 | 과거 소셜? | 비고 |
| --- | --- | --- | --- |
| 동영상/개인방송 | 1.68 | ✅ | 유튜브류(메타 아님 다수) |
| 커뮤니케이션 | 1.12 | ❌ | 카톡·메신저·SNS — 제외됐었음 |
| SNS | 0.02 | ✅ | KISDI가 거의 안 잡음 |

**해결:** reach 가중 출처를 KISDI 프록시 → **메타(인스타/페북) 연령별 침투율 곡선**(`data/.../meta_reach.json`)으로 교체. 샘플러 `_cell_reach`가 이 곡선을 사용. 결과적으로 30대가 25%로 정상화되고 50대+가 급감(§8 표).

**데이터 출처(2026-06-16 실측 반영):** 20~40대는 **한국언론진흥재단 「2024 소셜미디어 이용자 조사」**(만 19세+, n=3,000, ±1.8%p)의 인스타그램 이용률 — **20대 80.9% · 30대 70.7% · 40대 47.5%**. 인스타그램을 메타 도달 프록시로 사용(한국에서 페북은 더 낮고 감소세라 인스타가 메타 도달을 좌우).

**아직 추정치인 구간(`needs_real_values: true` 유지) — 사용자 수집 가이드:**

| 구간 | 현재값 | 왜 추정 | 정확화 방법 |
| --- | --- | --- | --- |
| **10-19** | 0.80 | KPF가 만 19세+라 미포함 | KPF 원본 보고서(10대 별도 조사) 또는 오픈서베이(만 15세+) 다운로드 |
| **50-59 / 60-69 / 70+** | 0.30 / 0.12 / 0.04 | 기사엔 밴드만 강조, 인스타 수치 비공개 | KPF 원본 보고서 **전체 연령 교차표**(요약 기사엔 없음) |
| 성별 세분 | 미구분 | 연령만 사용 | 추후 |

> **가장 정확한 대안 — Meta 광고 관리자 '잠재 도달(potential reach)':** 메타 광고 계정에서 한국 × 연령 × 지역 잠재 도달 인구를 직접 조회하면 "메타가 실제 도달하는 인구"를 그대로 얻는다. **로그인 필요라 제(AI)가 수집 불가 → 사용자가 직접 추출** 필요. (이게 있으면 KPF 추정 전부 대체 가능.)
- KISDI `cell_social_reach`는 노출맥락(`exposure_context`) 선택과 참고 기록(`social_feed_reach`)에만 계속 사용.

### (2) 지역 메타 접근성 미반영
- 현재 **지역(시도)은 순수 인구 분포(행안부)** 로만 추출하고 메타 접근성 보정을 하지 않는다(연령·성별만 reach 적용).
- 고도화: 시도별 SNS/메타 이용률 데이터(예: KISDI 지역×SNS, 통계청 지역별 인터넷이용)를 확보해 지역 가중에도 반영. 단 지역별 SNS 격차는 연령만큼 크지 않아 **우선순위는 낮음**.

### (3) generic SNS 기준
- reach는 "일반 소셜" 기준이며 Meta 브랜드 특정 침투율 보정은 (1-A)와 함께 Tier 2.

## 10. 한 문장 요약

**한국 실데이터(인구·OCEAN·미디어·소비가치)에서 통계적으로 속성을 뽑아 "서로 다른 1,000명"을 먼저 확정하고(LLM 없음), LLM에게는 (4-a) 그 속성을 인물 소개로 풀고 (4-b) 그 사람으로서 광고에 반응하는 일만 시킨다. 숫자 KPI는 LLM이 아니라 집계 엔진이 코드로 계산한다.**

```
데이터 → [샘플러: 단계1~3] → Persona → [LLM 4-a: 서사] → 고정 패널(캐시)
                                          → [LLM 4-b: 반응 JSON] → [집계 엔진: KPI]
```
