# 페르소나 반응 프롬프트 워크플로우 & 데이터 수집 가이드

> **이 문서의 목적** — ① 지금까지 한 작업이 "가상 소비자(페르소나)가 광고에 반응하는 한 번의 과정"에서 **어디에 들어가는지**를 프롬프트 관점으로 보여주고, ② 네가 **직접 받아야 할 데이터의 주소와 받는 방법**을 안내한다.
> 작성 2026-06-22. (URL은 변경될 수 있음 — 깨지면 기관 메인에서 동일 명칭 재검색)

## 0. 한눈에 — 페르소나 한 명이 광고에 반응하기까지

```
┌─ ① 패널 빌드 (오프라인, 1회) ─ 페르소나 "누구인지"를 통계로 생성 ───────────┐
│  단계1 인구(나이·성별·지역)                                                  │
│   → 단계2-α 성격(OCEAN) ......................... ★B-6 (실데이터 연령 조건화)│
│   → 단계2-β 미디어 행동 ......................... ★작업2 (OCEAN→행동 조건화) │
│   → 단계3 소비가치 ............................. ★작업2 (OCEAN→행동 조건화) │
│              + 한국 특화 심리(체면·동조·눈치) ... ★작업4 (필드·현재 빈 값)  │
│   = Persona 객체 1,000명                                                     │
└──────────────────────────────────────────────────────────────────────────────┘
            │  (표본 추출 분포: ★작업5 Meta 도달, 가중치: ★작업2 raking)
            ▼
┌─ ② 광고 해석 (광고마다, 1회 공유) ────────────────────────────────────────┐
│  interpret_ad(VLM) → 업종·메시지·타깃·비주얼                                │
│   + 브랜드 인지율 룩업 ......................... ★작업1 (Tier3, 현재 빈 값) │
└──────────────────────────────────────────────────────────────────────────────┘
            ▼
┌─ ③ 반응 생성 (페르소나 × 광고) ── 여기서 프롬프트가 조립된다 ──────────────┐
│  _prompt(persona, ad) → Gemini → PersonaReaction(클릭의향·구매의도·발화...) │
└──────────────────────────────────────────────────────────────────────────────┘
            ▼
┌─ ④ 집계 ─ 숫자를 코드로 ──────────────────────────────────────────────────┐
│  가중 평균·신뢰구간 ............................ ★작업2 raking(가중치 정합)  │
└──────────────────────────────────────────────────────────────────────────────┘
```

**핵심 원칙(변함없음)** — 다양성은 데이터가 강제(LLM 아님), 사실은 공유 1회, 숫자는 코드·문장은 LLM. 모든 작업은 이 위에서만 보완.

## 2. 반응 프롬프트 워크플로우 관점 (핵심)

페르소나가 광고에 반응할 때 LLM에 들어가는 프롬프트는 `reaction.py`의 `_prompt()`가 조립한다. **지금까지 한 작업은 대부분 이 프롬프트의 특정 줄을 채우거나 정확하게 만드는 일이었다.**

### 2-1. 프롬프트가 만들어지는 코드 경로 (한 번의 `react` 호출)

`adapters/gemini/reaction.py`의 `GeminiReactionEngine.react()` 한 번이 페르소나 1명의 반응을 만든다.

```
react(persona, ad)                                   # reaction.py
  1) exposure = _pick_exposure(persona, rng)         # 노출 맥락 1개 선택(소셜피드 후보 중)
  2) prompt   = self._prompt(persona, ad, exposure)  # ↓ 아래 순서로 문자열 조립
  3) data     = await _agen_json(client, model, prompt, temperature=1.0)  # Gemini 호출(JSON 강제)
  4) return PersonaReaction(aisas, purchase_intent, trust, rejected, emotion, utterance, ...)
```

`_prompt()`는 **[나](페르소나) → [광고] → [출력 형식]** 순으로 조각을 이어 붙인다. 각 조각은 함수 하나가 만들고, 그 함수는 특정 데이터로 채워진 페르소나/광고 필드를 읽는다.

```
[나]  ← 페르소나 (패널 빌드 때 단계1~3에서 채워짐)
  · 기본:     age · gender · region · 학력 · 월소득
  · OCEAN:    persona.ocean                       (★B-6)
  · 미디어:   media_behavior.primary_medium
  · 소비가치: consumption_values                  (★작업2 조건화)
  · 노출맥락: _pick_exposure(persona)
  · 한국심리: _social_values_lines(persona)        (★작업4 — ⛔빈값이면 줄 생략)
  · 세대:     _generation_lines(age)              (Tier1)
[광고]  ← AdInterpretation (interpret_ad에서 1회 산출, 전 페르소나 공유)
  · 감지:     detected_industry / message / target
  · 특성:     _ad_feature_lines(ad, income)        (가격·사회적 증거)
  · 비주얼:   _visual_lines(ad)                    (structured_analysis.visual_elements)
  · 인지도:   _awareness_lines(ad, age)           (★작업1 — ⛔빈값이면 줄 생략)
[출력]  ← AISAS · 구매의도 · 신뢰 · 거부 · 감정 · 발화 (구조화 JSON 강제)
```

### 2-2. 데이터 → 프롬프트 end-to-end 추적 (어떤 데이터가 어디에 영향을 주나)

데이터 파일 한 개가 loader → 페르소나/광고 필드 → 프롬프트 조각으로 어떻게 이어지는지의 전체 사슬이다.

| 데이터 파일(출처) | loader 함수 | 페르소나/광고 필드 | 프롬프트 조각 | 만드는 함수 |
| --- | --- | --- | --- | --- |
| `population_age_sex.csv`(행안부) | `load_population_age_sex` | age·gender·region | `[나] 27세 F, 서울` | `_build_persona` |
| `ocean_age_bands.json`(카카오 OSF) | `load_ocean_age_bands` | `ocean` | `[나] OCEAN: {...}` | `_sample_ocean` ★B-6 |
| `socioeconomic.json`(KISDI) | `load_socioeconomic` | `socioeconomic`(소득·학력) | `[나] 학력·월소득` + 가격 적합도 | `_sample_socioeconomic`·`_ad_feature_lines` |
| `media_behavior.json`(KISDI) | `load_media_behavior` | `media_behavior`(주매체·노출후보) | `[나] 주 이용 미디어`·`노출 맥락` | `_sample_media`·`_pick_exposure` |
| `consumption_values.json`(대학내일) | `load_consumption_values` | `consumption_values` | `[나] 중시 소비가치` | `_sample_consumption` ★작업2 |
| `social_values_deep.json`(MDIS) | `load_social_values_deep` | `social_values_deep` | `[나] [내 성향(한국특화)]` | `_sample_social_values_deep` ★작업4 ⛔(MDIS 2025 사회조사에도 체면·동조·눈치 대응 문항 없음, 확인 완료 2026-07-03) |
| `social_economic.json`(MDIS 사회조사 2025) | `load_social_economic` | `social_economic`(생활만족·대인신뢰·소득충족·계층상향·사회참여) | `[나] [내 사회경제 성향]` | `_sample_social_economic` ✅ 완료 |
| `meta_reach.json`(Meta 광고관리자) | `load_meta_reach` | (표본추출·`meta_reach` 속성) | — (프롬프트 아님, §2-5) | `_reach_marginal` ★작업5 |
| `brand_awareness.json`(갤럽) | `load_brand_awareness` | `ad.structured_analysis.awareness_by_age` | `[광고] [브랜드 인지도]` | `lookup_brand_awareness`→`_awareness_lines` ★작업1 ⛔ |
| (VLM 광고 이미지·카피) | `GeminiAdInterpreter` | `ad.detected_*`·`ad_features`·`visual_elements` | `[광고] 업종/메시지/타깃·비주얼 | `_ad_feature_lines`·`_visual_lines` |

> ⛔ = 현재 데이터가 비어 해당 프롬프트 조각이 **생략**됨(현 동작 유지). 데이터를 채우면 그 조각이 살아난다.

### 2-3. 실제 프롬프트 구조 (어느 작업이 어느 줄을 만드나)

```
당신은 아래 한국 소비자 '본인'입니다. 지금 인스타그램·페이스북(메타) 피드를 넘겨보다가 아래 광고를 마주쳤습니다. 이 사람의 성격·형편·미디어 습관에 충실하게 반응하세요. (피드 광고라 관심 없으면 즉시 넘길 수 있음)

[나]
- 27세 F, 서울
- 학력 대졸, 월소득 250~300만원
- OCEAN(표준화, 양수=평균이상): {openness:0.4, conscientiousness:-0.1, ...}   ← ★B-6
- 주 이용 미디어: 스마트폰/휴대폰                                            ← 기존 KISDI
- 중시 소비가치: ['성능','품질','취향·덕질']                                  ← ★작업2(OCEAN 조건화)
- 서사: (없음)
- 지금 노출 맥락: 저녁·집·스마트폰·SNS                                       ← 기존 KISDI 소셜맥락
  [내 성향(한국 특화)] 체면 65%, 동조 …                                      ← ★작업4 (지금은 값 비어 줄 자체가 생략)
  [내 세대] 형성기 2013~2023 …                                              ← Tier1(기존)

[광고]
- 업종: 화장품 / 메시지: …   ← 추정 타깃은 주입 안 함(앵커링 방지, perceived_target은 페르소나가 스스로 출력)
  (가격·사회적 증거 …)                                                       ← 기존 ad_features
  [광고 비주얼] 첫눈에 띄는 것: … / 색감 …                                    ← 기존 VLM
  [브랜드 인지도] OOO는 내 또래(20-29) 인지도 약 75% …                        ← ★작업1 (지금은 데이터 비어 생략)

[출력] aisas/구매의도/신뢰/거부/감정/발화 … (구조화 JSON)
```

### 2-4. 줄 ← 작업 ← 데이터 매핑

| 프롬프트 줄 | 만드는 함수 | 작업 | 필요 데이터 | 지금 |
| --- | --- | --- | --- | --- |
| `OCEAN: {...}` | `_sample_ocean` | **B-6** | OSF OCEAN(보유) | ✅ 실데이터로 작동 |
| `중시 소비가치` | `_sample_consumption` | **작업2** 조건화 | 없음(문헌 prior) | ✅ 항상 작동(소폭) |
| `[내 성향(한국 특화)]` | `_social_values_lines` | **작업4** | MDIS + 척도 정의 | ⛔ 데이터 비어 **줄 생략**(현 동작) |
| `[브랜드 인지도]` | `_awareness_lines` | **작업1** | 갤럽/오픈서베이 인지율 | ⛔ 데이터 비어 **줄 생략**(현 동작) |
| `주 이용 미디어`·`노출 맥락` | `_sample_media`·`_pick_exposure` | 기존(KISDI) | 보유 | ✅ 작동(이번 작업이 바꾸지 않음) |
| `[내 세대]` | `_generation_lines` | Tier1(기존) | 없음(나이) | ✅ 작동 |

> **읽는 법** — "⛔ 줄 생략"은 데이터가 없을 때 그 줄이 프롬프트에 **아예 안 들어가** 현재 반응이 바뀌지 않는다는 뜻이다. 네가 해당 데이터를 채우면 그 순간부터 줄이 살아나 페르소나 반응에 반영된다.

### 2-5. 프롬프트에는 안 보이지만 결과를 바꾸는 작업

이 작업들은 프롬프트 텍스트가 아니라 **표본 구성·가중치·저장 속성**에 작용한다.

- **작업5 Meta 도달(플랫폼)** — 어떤 페르소나를 **표본으로 뽑을지**(추출 분포)와 페르소나의 `meta_reach` 속성을 바꾼다. 반응 프롬프트 텍스트에는 안 나온다 → "패널 구성"에 영향.
- **작업2 raking** — 페르소나의 **가중치(weight)**를 census에 정합시켜 ④ 집계(가중 평균·신뢰구간)에 반영. (opt-in `rake_to_census`, 기본 OFF)
- **작업2 미디어 조건화** — 개방성·외향성↑이면 `daily_media_minutes`(이용시간)를 소폭↑. 페르소나에 저장되지만 이 반응 프롬프트에는 노출되지 않음(소비가치 조건화만 프롬프트에 보임).

### 3-1. MDIS 사회조사 raw — 체면·동조·눈치(작업4), 성격×소비 상관(작업3) `🟡 로그인 게이트`

> **직접 다운로드 링크는 제공 불가** — MDIS는 로그인 + 항목 선택 + 추출요청을 거쳐야 파일이 나오는 세션 기반이라 "클릭하면 바로 받는 주소"가 없다. 아래 절차를 따른다.

1. **접속·가입** — https://mdis.kostat.go.kr 접속 후 회원가입(공공용 자료 무료). (접속 안 되면 국가데이터처 도메인 https://mdis.mods.go.kr 시도)
2. **사회조사 데이터셋(바로가기)** — https://mdis.kostat.go.kr/ofrData/selectOfrDataDetail.do?survId=34&itmDiv=1&itemId=2002 (사회일반 > **사회조사**, survId=34). 또는 공공용 자료 검색 https://mdis.kostat.go.kr/dwnlSvc/ofrSurvSearch.do?curMenuNo=UI_POR_P9240 → "**사회조사**" 검색.
3. **다운로드** — 로그인 후 `자료 이용 > 다운로드 서비스`에서 연도 선택 → 항목 선택(**가치관·생활만족·소비태도 + 연령·성별**) → CSV/SPSS/SAS 추출. (이용법: https://mdis.kostat.go.kr/pageLink.do?link=content/SISMN070100) ※ "200레코드 제한"은 미리보기 샘플만, 공공용 전체는 무료.
4. **가공** — 가치관 문항 중 **체면(타인 시선)·동조(남들 따라)·눈치(분위기 읽기)** 에 대응하는 문항을 골라 **세대별 평균(0~1)** 으로 환산.
   - ⚠️ 체면·동조·눈치는 표준 척도가 아니다 → 어느 문항을 쓸지 **정의·매핑에 전문가 검토 필요**(이 단계가 작업4의 진짜 게이트).
5. **넣기** — `distributions/social_values_deep.json`의 `generation_specific`을 채운다(아래 §4-3 형식).

### 3-2. KISDI 한국미디어패널 raw — IPF 정밀 결합(작업2) `🟡 로그인 게이트`

> 원시자료는 회원가입 후 게시판에서 받는다 — 직접 다운로드 링크 없음(아래 절차).

1. **접속·가입** — 미디어통계포털 https://stat.kisdi.re.kr/main.html → 회원가입.
2. **원시자료** — 원시자료 게시판 https://stat.kisdi.re.kr/kor/board/BoardList.html?board_class=BOARD35 (설문지·원시자료)에서 최신 연도 raw 다운로드.
3. **가공** — "연령 × 성별 × 미디어 이용 패턴" 교차표 산출(미디어 다이어리 포함).
4. **용도** — IPF 결합분포의 **행동 marginal** 입력(현재 raking은 인구 marginal만; KISDI로 행동 차원 추가 시 정밀화). 대용량이라 Claude 자동 수집 불가, 네가 받아야 함.

### 3-3. KOSIS 인구 결합표 — raking 타깃(작업2) `🟢 직접`

- **바로가기(통계표)** — 주민등록 인구 성/연령: https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1B040A3 → 우상단 "다운로드"로 CSV/Excel. 행정동 단위 파일은 data.go.kr https://www.data.go.kr/data/15097972/fileData.do (로그인 불필요).
- **자동화** — KOSIS OpenAPI 인증키 발급(무료, https://kosis.kr/openapi) → 시군구/성/연령 호출.
- **용도** — `rake_to_census` 타깃. 현재 보유 인구 marginal(행안부)로 이미 raking 가능 — KOSIS는 더 세분한 결합(지역·소득 등)이 필요할 때.

### 3-4. 인터넷이용실태/SNS 연령별 — Meta 부분(작업5) `🟢 직접(부분)`

- **바로가기(통계표)** — KOSIS 주로 이용하는 SNS(연령별): https://kosis.kr/statHtml/statHtml.do?orgId=405&tblId=DT_405001_I127 . 전체 검색은 https://kosis.kr 에서 "인터넷이용실태조사" / "SNS 이용률".
- **보조 자료** — KISDI 세대별 SNS 이용 현황 리포트 https://www.kisdi.re.kr · 한국언론진흥재단 소셜미디어 이용자 조사 https://www.kpf.or.kr (둘 다 공개 리포트).
- **한계** — generic SNS·동영상 연령별 이용률만(인스타/페북 **브랜드 분리는 없음**). 작업5의 "통합→IG/FB 분리"를 **완전히 풀지는 못함**(보조 신호용). 정확한 IG/FB 연령×성별 침투율은 §3-6 계약/광고관리자 데이터가 필요.

### 3-5. 한국갤럽 브랜드 트래킹 — 브랜드 인지율(작업1) `🔴 계약`

- **출처** — 한국갤럽 https://www.gallup.co.kr → 문의/리서치 의뢰. 갤럽 브랜드 트래킹은 업계 표준 정기 유료 상품(브랜드×연령 인지·선호·사용).
- **대안** — 오픈서베이 https://www.opensurvey.co.kr 에 **Custom Survey**로 특정 브랜드 연령별 보조인지율 의뢰(주문형). 또는 **클라이언트(광고주)가 보유한 브랜드 트래킹 데이터** 제공받기.
- **넣기** — `distributions/brand_awareness.json`의 `brands`를 채운다(아래 §4-1).

## 4. 데이터 넣는 형식 (스키마 예시)

받은 데이터를 아래 형식으로 해당 JSON에 채우면 코드가 자동으로 활성화된다(코드 수정 불필요). 각 파일에는 `_schema_example`도 들어 있다.

### 4-1. `distributions/brand_awareness.json` (작업1)

```json
"brands": {
  "올리브영": {
    "aliases": ["oliveyoung", "올영"],
    "industry": "화장품·헬스",
    "awareness_by_age": {
      "10-19": 0.82, "20-29": 0.91, "30-39": 0.88,
      "40-49": 0.74, "50-59": 0.55, "60-69": 0.38
    },
    "source": "한국갤럽 브랜드 트래킹 2026",
    "year": 2026
  }
}
```
- `awareness_by_age`는 0~1 보조인지율. 광고 텍스트(제목·메시지)에 브랜드명/별칭이 들어 있으면 해석에 부착되고, 페르소나는 **자기 연령대 칸만** 읽는다.

### 4-2. `distributions/meta_reach.json` → `platform_specifics` (작업5)

```json
"platform_specifics": {
  "instagram": {
    "age_bands": { "10-19": 0.12, "20-29": 0.38, "30-39": 0.26, "40-49": 0.14, "50-59": 0.07, "60-69": 0.03 },
    "by_age_gender": { "20-29|F": 0.45, "20-29|M": 0.31, "30-39|F": 0.30 }
  },
  "facebook": {
    "age_bands": { "10-19": 0.05, "20-29": 0.22, "30-39": 0.28, "40-49": 0.22, "50-59": 0.14, "60-69": 0.09 },
    "by_age_gender": {}
  }
}
```
- `age_bands`(연령 marginal, 합≈1)만 채워도 작동. `by_age_gender`("연령|성별" 키)는 선택. 사용하려면 wiring에서 `meta_platform="instagram"` 지정. 비우면 통합 reach 폴백(현 동작).

### 4-3. `distributions/social_values_deep.json` → `generation_specific` (작업4)

```json
"generation_specific": {
  "Z세대":      { "체면": 0.45, "동조": 0.38, "눈치": 0.72 },
  "밀레니얼":   { "체면": 0.52, "동조": 0.48, "눈치": 0.75 },
  "X세대":      { "체면": 0.65, "동조": 0.62, "눈치": 0.80 },
  "베이비부머": { "체면": 0.72, "동조": 0.70, "눈치": 0.78 }
}
```
- 0~1 값. 채우면 페르소나에 세대별로 실리고 반응 프롬프트 `[내 성향(한국 특화)]` 줄이 살아난다. 세대 구분: Z세대 ≤29, 밀레니얼 30~44, X세대 45~59, 베이비부머 60+.
