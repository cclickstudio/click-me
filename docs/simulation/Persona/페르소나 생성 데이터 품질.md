# 페르소나 생성 데이터 품질 리포트

> 현재 페르소나 생성에 쓰는 **데이터 품질**, 제한된 한국 데이터로 **어떻게 생성하는지(방법)**, 그렇게 만든 **페르소나의 품질**, 그리고 **발견한 문제와 해결**을 한곳에 정리한다. 모든 수치는 실제 샘플링·진단 실행 결과(2026-06-22).
>
> **한 줄 결론** — 인구학적으로 진짜고 다양하며 나이·성별별 성격 구배가 살아 있다(B−/B). 단 OCEAN 자기선택 편향·속성 간 상관 부재·출력 검증 부재가 남은 한계다. 목표("직감보다 나은 의사결정 근거")엔 충분하나 "실제 한국인 한 명"엔 아직 못 미친다.

## 2. 제한된 한국 데이터로 생성하는 방법

한국은 "성격·미디어·소비를 개인 단위로 동시에 가진" 공개 데이터가 없다. 그래서 **여러 출처를 단계별로 조건부 결합**하는 전략을 쓴다.

1. **다양성 = 데이터가 강제 (LLM 아님).** 단계1~3은 순수 통계 샘플링. "30대 여성 만들어줘"를 LLM에 시키면 학습 평균으로 수렴(동질화)하므로, 속성은 전부 실분포에서 뽑는다. LLM은 4-a(서사)·4-b(반응)에서만 등장.
2. **표본 + 가중.** 전수 시뮬레이션 대신 수백 명 표본 + 가중치로 5,109만을 추정. `페르소나반응` 행은 표본 수와 정확히 일치(부풀림 금지).
3. **연령×성별 조건화.** OCEAN을 `by_age_gender_band`(OSF class×age×gender 직접 산출)로 뽑아, 나이·성별에 맞는 성격 분포 적용. 폴백: `by_age_gender_band` → `by_age_band` → `default`.
4. **잔차 offset.** 유형비율 조건화만으론 성숙원리 factor 이동의 일부만 잡힌다(60+ 성실성 ≈0.11). 실측 밴드평균 − 유형혼합 함의 평균을 가산해 밴드 marginal을 실측(0.87)에 정합.
5. **경량 OCEAN→행동 조건화.** 진짜 성격×행동 결합 데이터가 없으니, 문헌 prior로 소폭만 연결(개방성↑→다양·니치, 성실성↑→품질 중시). 가짜 joint는 만들지 않고 보류.
6. **외부 marginal raking.** 도달성 과표집 등으로 틀어진 가중치를 census 연령·성별에 IPF로 되돌림(opt-in).
7. **Graceful fallback + 투명성.** 데이터가 없으면 현재 동작 보존(회귀 0), `data_status()`로 real/placeholder/pending 정직 표기.
8. **Framework-for-pending.** 미확보 항목(체면·동조·눈치, 브랜드 인지율)도 Persona 필드·반응 프롬프트까지 배선해 두고, 데이터 주입 시 즉시 활성화(값 비면 줄 자동 생략).
9. **고정 패널.** 같은 패널을 재사용해 A/B 비교 타당성·재현성 확보.

> 즉 "부족한 데이터를 LLM으로 메우지 않고, 있는 실데이터를 조건부로 정밀 결합하고, 없는 건 정직하게 비워두는" 방식이다.

## 3. 생성된 페르소나의 품질 (실측 진단)

800~1,000명을 실제 생성해 측정한 결과.

**✅ 강점**
- **완전한 다양성** — 800명 전원 고유 (나이, OCEAN) 조합, 고유 나이 71개. 동질화 0.
- **성숙 구배가 깨끗** — 성실성 14-19 **−0.28** → 60+ **+0.78**, 신경증 **+0.39** → **−0.63** (단조). 실데이터가 그대로 보임.
- **성별 차이 반영** — 같은 연령대에서 여성 신경증·친화성 ↑ (신경증 M −0.48 / F −0.28, 친화성 M +0.10 / F +0.34). 연령×성별이 동시 작동.
- **인구 현실성** — 성별 49.6:50.4, 지역 경기 > 서울 (census 일치).

**⚠️ 한계 (실측에서 드러남)**
- **연령이 60+로 쏠림** — default census 경로에선 60+ 32.8% vs 20대 12.0%. 인구론 맞지만(고령화 + 60+가 60~84 광역밴드 + 14세 미만 제외) **디지털 광고 대상엔 비현실적**. production은 reach 가중으로 젊게 보정(경로 의존).
- **간헐적 비현실 조합** — 예: 19세 남성의 주매체가 "신문·잡지·책 350분". 속성을 독립적으로 뽑고 결합 검증이 없어 가끔 앞뒤 안 맞는 조합이 나옴.

**예시 페르소나(실제 생성)**
```
27세 M 경기 / 대졸·100만미만 / 성격: 개방성 매우낮음·외향성 보통·신경증 매우낮음 / PC 307분
43세 F 인천 / 대졸·소득없음 / 성실성 1.0·신경증 1.11 / TV 316분
66세 M 인천 / 중졸·500~800만 / 개방성 1.52·성실성 0.81 / TV 278분
```

## 4. 발견한 문제점과 해결

| # | 문제 | 발견 | 해결 | 상태 |
| --- | --- | --- | --- | --- |
| 1 | **남녀 성격 동일** — 성별이 OCEAN에 안 들어가 M=F(성실성 0.48=0.48) | 800명 진단 | OSF 원자료로 `by_age_gender_band` 재산출·주입, `_sample_ocean(age, gender)` | ✅ 해결 |
| 2 | **저렴한 가격이 Z세대 전용** → 50대 0% (가격 가치 없음) | 진단 | `consumption_values.json`에서 base로 이동 (가격 민감도는 비세대적) | ✅ 해결 |
| 3 | **OCEAN 자기선택 편향** — 카카오 자발 표본(여성 72%·평균 27.7세) | 논문 한계 | 성별 조건화로 **부분 완화**(남녀 분리). 대표성 자체는 못 고침 | △ 본질적 한계 |
| 4 | **속성 간 진짜 상관 부재** — 성격·미디어·소비가 대부분 독립 샘플링 | 코드 분석 | 경량 조건화 + raking으로 **부분** 보정. 개인단위 연결 데이터 부재로 진짜 joint는 보류 | △ 데이터 게이트 |
| 5 | **연령 60+ 쏠림(census 경로)** | 진단 | production은 reach 가중(`reachability_sampling`)으로 젊게 보정 | △ 경로 의존 |
| 6 | **간헐적 비현실 속성 조합**(예: 10대 print 주매체) | 진단 | 미해결 — 결합 검증/joint 필요 | ⬜ open |
| 7 | **출력 검증(calibration) 부재** — 실제 한국인 응답과의 정합을 모름 | 분석 | 미해결 — KOBACO/공개조사 방향 대조(A-2/A-3) 필요 | ⬜ open |

**이번 세션에서 실제로 고친 것** — #1(성별 조건화)·#2(소비가치 버그)는 코드·데이터로 해결하고 테스트(93 passed)로 회귀 0 확인. 나머지는 데이터 확보나 별도 설계가 필요한 항목으로 남겨 정직하게 표기.

## 5. 종합 판단

- **등급: B−** (이번 #1·#2 해결 후). LLM 생성(D/F)·placeholder(C 이하)보다 분명히 위.
- **쓸 수 있는 것** — "20대 vs 50대, 남 vs 여가 광고에 **다르게** 반응하는 방향" → 신뢰 가능(인구·성격 grounding 탄탄).
- **아직 못 하는 것** — "구매의도 3.7점"을 실측처럼 단언 → 부족(자기선택 편향·검증 부재).
- **숨은 품질** — 한계를 숨기지 않는다. `data_status` 투명 표기, 자기선택 편향 코드·문서 명시, "분포로 표기·평균 단언 금지" 강제. 전부 LLM으로 지어내고 대표성을 주장하는 제품과 대비되는 정직성.

**남은 과제 우선순위**
1. **출력 검증 1건**(A-2/A-3) — "정확도를 모른다"를 "방향은 맞다"로. 가장 의미 있는 다음 수.
2. **소비가치 13개 확장** + 체면·동조·눈치(MDIS) 주입 — pending 2종 해소.
3. **속성 결합 검증** — 비현실 조합(#6) 억제. joint 데이터 확보 시.
