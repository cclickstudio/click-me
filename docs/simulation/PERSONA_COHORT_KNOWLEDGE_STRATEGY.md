# 페르소나 코호트·트렌드 지식 — 문제와 전략

> 페르소나가 자기 세대·시대에 맞는 브랜드·상품·캐릭터 지식으로 반응해야 하는데, 그 지식이 데이터에 없고
> LLM에 떠넘겨져 있다. LLM은 실제 사람과 정반대로 "모든 시대를 균일하게" 알아서 시대착오 반응이 난다.
> 결론: **반응 단계에 페르소나별 검색을 달지 말고, ① 프롬프트로 '형성기' 세대 게이팅을 걸고
> ② 브랜드 시대성을 해석 단계에서 1회 추출해 공유 주입한다. 실데이터 주입은 Phase 2.** (작성일: 2026-06-19)

> 선행 문서: [PERSONA_GENERATION_STRATEGY.md](./Persona/PERSONA_GENERATION_STRATEGY.md) (다양성=데이터 철학) ·
> [PERSONA_LLM_COST_STRATEGY.md](./PERSONA_LLM_COST_STRATEGY.md) (모델 선택) ·
> [VLM_PER_PERSONA_VISION.md](./VLM_PER_PERSONA_VISION.md) (공유 해석 1회 + 페르소나별 조건화).

---

## 0. TL;DR

1. **현재 갭** — 페르소나는 "누구인지"(나이·OCEAN·소득·미디어습관)만 데이터로 박혀 있고, "무엇을 문화적으로
   아는지"(세대별 브랜드·캐릭터·트렌드 친숙도)는 데이터에 없이 LLM에 통째로 떠넘겨져 있다.
2. **왜 생기나** — LLM은 학습이 끝나면 가중치가 얼어붙고(continuous learning 아님), 모든 시대의 브랜드를
   **균일하게** 안다. 실제 사람의 **부분적·세대별** 기억과 정반대다. 그래서 게이팅을 안 걸면 시대착오가 난다.
3. **영향** — 가격·메시지 중심 광고엔 약하지만, 브랜드 헤리티지 광고·**타깃 세그먼트 차이(보고서 §3)**·
   **utterance 리얼리티**(킬러 파트)에선 치명적.
4. **전략** — 페르소나별 검색은 금지(비용·일관성·재현성 붕괴). 대신 **형성기(reminiscence bump) 게이팅(프롬프트)
   + 브랜드 시대성 1회 추출(해석 단계 공유)**. 다양성은 데이터(나이)에서, 사실은 공유 1회에서.

## 1. 현재 문제 — 무엇이 비어 있나

### 1.1 데이터가 박는 것 vs 안 박는 것

[`contracts/schemas.py`](../../backend/domain/simulation/contracts/schemas.py)의 `Persona`가 들고 있는 것:

```
age, gender, region, ocean, media_behavior, consumption_values, socioeconomic
```

→ 실데이터가 강제하는 건 **"이 사람이 누구냐"**(나이·성격·소득·미디어습관·가치관)다.
**"이 사람이 어떤 브랜드·상품·캐릭터를 알고, 그게 그에게 무슨 의미냐"는 어디에도 데이터로 없다.**
브랜드/카테고리 친숙도를 세대별로 차등하는 필드 자체가 없다.

### 1.2 반응 프롬프트는 나이를 주지만 게이팅을 안 시킨다

[`adapters/gemini/reaction.py`](../../backend/domain/simulation/adapters/gemini/reaction.py)의 `_prompt()`는
나이·OCEAN·소득·미디어·소비가치를 넘겨주지만, **"네 세대에 맞게 브랜드 친숙도를 조절하라"는 지시가 없다.**
그 결과 브랜드 지식의 세대 차등은 전적으로 LLM의 자율 추론에 맡겨지고, LLM은 이걸 약하고 불안정하게 한다.

> 즉 다양성을 단계 1~3에서 데이터로 강제해 놨는데(PERSONA 철학), 정작 **문화 지식 차원은 출력단에서
> LLM이 균일하게 풀어버려** 그 다양성이 다시 뭉개질 수 있다. Persona Collapse와 같은 결의 누수이되,
> 증상은 "동질화"가 아니라 **"시대착오"**다.

## 2. 왜 생기나 — LLM이 트렌드를 "기억"하는 방식

### 2.1 가중치는 얼어붙는다 (가장 큰 오해 정정)

LLM은 **계속 학습하지 않는다.** 학습이 끝나면 가중치가 고정되고, 대화하거나 시간이 지나도 스스로 새 지식을
흡수하지 않는다. 모델은 **학습 마감 시점(knowledge cutoff)까지의 데이터 스냅샷**이다.

### 2.2 최신성의 두 경로 — 둘은 완전히 다르다

| 경로 | 정체 | 실시간 | 우리 반응에 관여 |
|---|---|---|---|
| **① 재학습 → 새 버전** | 더 최신 데이터로 다시 학습해 `2.5`→`3.0` 출시. 버전마다 cutoff 갱신 | ✗ (월 단위) | 모델 교체 시에만 |
| **② 도구(웹서치/Grounding)** | 추론 시 검색 도구를 쥐어주면 검색어를 날려 결과를 컨텍스트에 끼움 | ✓ (호출마다) | **현재 미사용** |

모델이 최신 트렌드를 아는 건 대부분 **①(최근에 학습된 버전이라서)**이고, cutoff 이후·희귀 정보는 **②(검색)**로
메운다. ②는 학습이 아니다 — 그 순간 컨텍스트에 끼웠다가 답이 끝나면 잊는다.

### 2.3 검색은 opt-in이고, 우리 반응은 안 켜놨다 (코드 근거)

[`adapters/gemini/_common.py`](../../backend/domain/simulation/adapters/gemini/_common.py)의 실제 호출 설정:

```python
config = {"response_mime_type": "application/json"}  # (+ temperature)
```

**검색 도구도 grounding 설정도 없다.** 즉 반응 생성은 순수하게 Gemini의 얼어붙은 기억 + 프롬프트에 담아준
내용만으로 답한다. **광고가 모델도 모르는 브랜드여도 자체 검색하지 않는다** — 모르면 일반화하거나 환각한다.

### 2.4 핵심 미스매치 — 실제 사람과 정반대로 안다

| | 실제 사람 | LLM (기본) |
|---|---|---|
| 문화 지식 범위 | **부분적·세대별** | **신의 시점·전 시대 균일** |
| 60세 | 80~90년대 브랜드를 몸으로 앎, 요즘 Z세대 밈은 모름 | 둘 다 균일하게 앎 |
| 20세 | 요즘 트렌드에 밝고, 자기 출생 전 브랜드는 모름 | 둘 다 균일하게 앎 |

→ 게이팅을 안 걸면 **20세가 자기 태어나기 전 브랜드를 추억하고, 60세가 틱톡 밈을 술술 말하는** 거꾸로 된
반응이 나온다. 나이를 데이터로 정확히 박아도 출력단에서 시대착오가 나면 세그먼트 분석이 헛돈다.

## 3. 영향 — 어디서 깨지나 (경중)

| 경중 | 상황 | 이유 |
|---|---|---|
| **낮음** | 가격·메시지·비주얼이 스스로 말하는 광고 | 브랜드 사전지식 없이도 반응 가능 |
| **높음** | 브랜드 헤리티지·인지도 전제 광고(향수 마케팅, "다들 알지?") | 세대별 친숙도가 반응을 좌우 |
| **높음** | **타깃 세그먼트 차이(보고서 §3)** | 세대별 지식 차등이 없으면 세그먼트 인사이트가 가짜가 됨 |
| **높음** | **`utterance` 리얼리티(보고서 §3-2, 킬러 파트)** | 시대착오 발화 하나로 마케터 신뢰 붕괴 |
| **높음** | 무명·신생 브랜드 | 모델이 함의를 만들 재료가 없어 헛소리 위험(유명 브랜드보다 큼) |

## 4. 해결 전략 (3단)

### 4.1 지렛대 — 형성기(formative years / reminiscence bump)

소비자행동학상 사람의 브랜드·문화 애착은 대략 **15~25세**에 가장 강하게 형성된다(reminiscence bump).
**출생연도 → 형성기 구간**만 계산하면 "이 사람에게 어느 시대 브랜드가 native한가"를 추가 데이터 없이 나이만으로
가를 수 있다. 반응 프롬프트는 이미 나이를 넘기므로 즉시 적용 가능.

```
birth_year ≈ 현재연도 − age
형성기 ≈ (birth_year + 15) ~ (birth_year + 25)
```

### 4.2 단계별 방안

| Tier | 무엇 | 시점 | 비용 | 한계 |
|---|---|---|---|---|
| **1. 프롬프트 세대 게이팅 ✅ 적용 완료** | 형성기 구간 + **나이대 말투**를 프롬프트에 넣고 "네 나이에 비추어 친숙/생소를 판단, 모르면 모르는 대로 반응" 지시 (`reaction.py:_generation_lines`) | **완료(2026-06-19)** | 코드 몇 줄, 데이터 0 | LLM 자체 시대지식에 의존(브랜드 연대 오인 가능) |
| **2. 브랜드 시대성 1회 추출** | `interpret_ad`가 브랜드 시대·세대 관련성도 추출("전세대 국민/Z세대 native/90s 전성기") → 전 페르소나 공유 주입 | 다음 | 해석 1콜 확장 | 브랜드 식별 실패 시 무력 |
| **3. 실데이터 주입** | 세대별 브랜드 인지도 실측(한국갤럽 브랜드 트래킹·대학내일20대연구소)을 페르소나에 주입 | Phase 2 | 데이터 확보 비쌈 | 브랜드 단위 포괄 수집 난이도 |

### 4.3 Tier 1 — 적용 완료 (2026-06-19)

`reaction.py`에 `_generation_lines(age)` 헬퍼를 추가하고, `_prompt()`의 `[나]` 블록 뒤에 `[내 세대]` 단락으로
주입했다(나이는 이미 전달됨). DB·스키마·계약 변경 없음 — 순수 프롬프트 조건화.

```
[내 세대]
- 브랜드·문화 취향이 형성된 시기는 대략 {form_start}~{form_end}년입니다.   # birth_year = 현재연도 − age
- 그 시기에 익숙했던 브랜드·캐릭터·트렌드와, 요즘 젊은 세대가 쓰는 것에 대한 친숙도는 다릅니다.
  이 광고의 브랜드·소재가 '내 세대에 익숙한지'를 내 나이에 비추어 판단하고,
  잘 모르는 브랜드면 아는 척하지 말고 '낯섦'을 반영해 반응하세요.
- utterance(반응 문장)는 내 나이대가 실제로 쓰는 말투·어휘·어미로 말하세요.
  젊으면 젊은 대로, 나이 들면 그 세대의 자연스러운 어투로 — 단 과장된 유행어·밈 남발은 금지.
```

→ LLM의 시대 지식(Flash·70B급이면 유명 브랜드는 충분)을 **세대로 게이팅**하고, 거기에 **나이대 말투**까지
조건화해 utterance 리얼리티(§3 킬러 파트)를 끌어올린다. 무명 브랜드의 시대 오인은 Tier 2가 보완.

### 4.4 Tier 2 — 다음 (철학에 가장 정합)

브랜드 시대성을 **해석 단계에서 1회** 뽑아 공유하면, 반응 = **페르소나 나이(데이터) × 공유된 브랜드 시대 사실**로
계산된다. 페르소나마다 따로 검색하지 않으므로 일관성·재현성이 유지되고, 다양성은 나이(데이터)에서 나온다.
이는 [VLM_PER_PERSONA_VISION.md](./VLM_PER_PERSONA_VISION.md)의 "공유 해석 1회 + 페르소나별 조건화" 패턴과 동일한 결.

## 5. 설계 원칙 / 가드레일

1. **반응 단계 페르소나별 검색 금지.** N명이면 검색 N번 → 느리고 비싸고, 페르소나마다 다른 사실을 받아와
   노이즈·재현성(§3.6 패널 고정) 붕괴. 검색이 필요하면 **해석 단계에서 1회**, 그 결과를 공유 주입.
2. **다양성은 데이터(나이)에서, 사실은 공유 1회에서.** 브랜드 시대성은 '사실'이라 전원 동일해야 하고,
   그에 대한 친숙/반응 차이는 '나이'가 만든다. 둘을 섞지 않는다.
3. **모르는 건 모르게.** 친숙도 게이팅의 핵심은 "아는 척 억제"다. 무명 브랜드에 환각으로 함의를 지어내지 않도록
   프롬프트가 '낯섦 허용'을 명시한다.
4. **재현성 유지.** 모델 버전 핀(`_DEFAULT_MODEL`) 유지, 패널 고정. 게이팅 추가가 재현성을 깨지 않는다.

## 6. 합격 기준 / 검증

- **세대 정합성 A/B** — 유명 브랜드 1(예: 칠성사이다) + 무명 브랜드 1을 20대·40대·60대 각 N명에게 반응시켜
  **utterance의 시대 정합성**을 육안 확인. 60대가 헤리티지로, 20대가 "올드/생소"로 갈리면 게이팅 작동.
- **분산 보존** — aggregator의 `variance_warning`/`effective_n`으로 세그먼트 간 차이가 살아있는지 확인
  (게이팅이 오히려 동질화시키지 않는지).
- **시대착오 0건** — "출생 전 브랜드 추억" 같은 명백한 오류가 사라졌는지 스팟 체크.

---

## 7. 미해결·결정 필요

- **형성기 구간 폭** — 15~25세 잠정. 카테고리별로 조정 여부(예: 캐릭터/게임은 더 어린 시기).
- **Tier 2 추출 스키마** — 브랜드 시대성을 어떤 enum/필드로 표현할지(`detected_brand_era` 등) → 해석 스키마 변경은
  공통부 협업 규칙 + Alembic 대상인지 확인.
- **무명 브랜드 fallback** — 식별 실패 시 "일반 신생 브랜드"로 둘지, 검색 1회를 해석 단계에 붙일지.
- **실데이터(Tier 3) 트리거** — 클라이언트가 브랜드 단위 정확도를 요구할 때만 착수.

---

## 8. 한 문장 요약

**LLM은 학습이 끝나면 얼어붙어 모든 시대 브랜드를 균일하게 알기에, 세대별로 부분적인 실제 사람과 반대다.
이 시대착오는 반응에 검색을 달아 푸는 게 아니라, 형성기 게이팅(프롬프트)과 브랜드 시대성 1회 추출(해석 공유)로
풀고, 다양성은 데이터(나이)에서·사실은 공유 1회에서 나오게 한다.**
