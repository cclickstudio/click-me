# 메타 접근성(reach) 비율 — 문제 정리와 데이터 추출 가이드

> 메타 전용 플랫폼에서 페르소나를 "메타를 실제로 접하는 인구 비율"로 생성하기 위한 reach 데이터의
> ① 그동안 발견한 문제 ② 현재 상태 ③ 정확한 실측 데이터를 직접 추출하는 방법을 정리한다.

---

## 1. 배경 — 왜 메타 접근성 비율이 필요한가

ClickMe는 **Meta(인스타그램·페이스북) 광고 전용** 플랫폼이다. 따라서 페르소나 집합도 한국 전체 인구가 아니라 **"메타를 실제로 접하는 인구"** 의 연령·성별 비율을 따라야 한다.

- 단계1(인구통계)에서 셀 가중치 `w = 인구비중 × 메타 침투율`로 추출 → 메타 도달층(젊은 층)에 표본이 집중.
- 구현: `tools/sampling/persona_sampler.py`의 `_cell_reach`, 데이터: `data/simulation/distributions/meta_reach.json`.

---

## 2. 발견한 문제들 (시간순)

### 문제 ① "20대가 압도적"이 아니다 — 과장된 기대
- 처음 문서에 "20대 압도·60~70대 거의 없음"이라 적었으나 **틀림**. 도달성 보정 효과는 중간 정도이고 한국 인구가 40~60대에 두꺼워 중장년도 많이 남는다.

### 문제 ② 작은 표본에서 비율이 출렁인다 — 표본 노이즈
- 페르소나를 **확률(20% 확률)** 로 독립 추첨하던 구조라, 20명에선 20대가 5%로도 나왔다.
- **해결:** `proportional`을 **쿼터(정수 비례 배분, 최대잔여법)** 로 변경 → 작은 표본도 "인구 20% → 표본 ~20%" 고정.

### 문제 ③ (핵심) reach가 "메타"가 아니라 "유튜브 영상 시청"이었다 ⚠️
- 과거 reach는 KISDI 미디어 다이어리에서 `{"SNS","동영상/개인방송"} @ 스마트폰/PC` 비중으로 계산.
- 그런데 **KISDI에서 "SNS" 라벨이 거의 비어 있었다(전체 노출확률 합 0.02)** → reach ≈ "동영상/개인방송(유튜브)" 시청 비중만 측정.
- 피드 스크롤에 가까운 **"커뮤니케이션"(카톡·SNS, 1.12)은 비소셜로 제외**.
- 결과: reach가 메타 사용이 아니라 유튜브 시청 패턴이라 **30대(0.068)가 40대(0.073)보다 낮은** 비현실적 곡선. 메타 핵심층(20~30대)이 안 두드러지는 주범.

| KISDI 행위 라벨 | 노출확률 합 | 과거 소셜 판정 |
| --- | --- | --- |
| TV/방송시청 | 6.85 | ✗ |
| 동영상/개인방송(유튜브) | 1.68 | ✅ |
| 커뮤니케이션(카톡·SNS) | 1.12 | ✗ ← 제외됨 |
| SNS | **0.02** | ✅ (거의 0) |

- **해결(Tier 2):** reach 출처를 KISDI 프록시 → **메타 연령별 침투율 곡선**(`meta_reach.json`)으로 교체. `_cell_reach`가 이 곡선을 사용. → 30대 25%로 정상화, 50대+ 급감.

### 문제 ④ 지역은 메타 접근성 미반영
- 연령·성별에만 메타 침투율을 적용하고 **지역(시도)은 순수 인구 분포(행안부)** 그대로. 지역별 메타 이용률 데이터 부재 → **추후 고도화**.

## 3. 현재 데이터 상태 (`meta_reach.json`) — Tier2-A 실측 확정 (2026-06-17)

**KPF 침투율 추정안은 폐기**하고, **Meta 광고 관리자 '추산 잠재고객 규모' 실측 도달 분포**로 교체했다. 이유는 §3.1 참고.

### 3.1 왜 침투율(KPF)이 아니라 도달 분포(Meta)인가
- 침투율 = 도달÷연령인구. 그런데 **메타 추산치가 통계청 인구를 초과**한다(예: 메타 20대 도달 ~9.58M > 한국 20대 인구 ~6.3M). 복수 계정·연령 자기기입 때문. → 나누면 **침투율이 1.0을 넘어 정의가 깨진다.**
- 따라서 메타 추산치는 "침투율"이 아니라 **그 자체가 '메타 도달 인구 marginal'**. 인구비중을 다시 곱하면 인구 이중적용.
- **결론(Tier2-A):** `meta_reach.json`을 도달 점유율 분포로 저장하고, 샘플러는 `reachability_sampling` ON일 때 이 분포를 **연령 marginal로 직접 사용**(`_reach_marginal`, 인구비중 곱 제거). 성별만 `male_ratio`로 분할.

### 3.2 측정 원본 (Meta 광고 관리자, 대한민국·전체 성별·어드밴티지+ OFF, 2026-06-17)
| Meta 구간 | 추산 잠재고객(중앙값) |
| --- | --- |
| 13-17 | 695,150 |
| 18-24 | 6,100,000 |
| 25-34 | 10,450,000 |
| 35-44 | 6,250,000 |
| 45-54 | 3,900,000 |
| 55-64 | 1,950,000 |
| 65+ | 875,250 |
| **합** | **30,220,400** |

### 3.3 우리 10년 밴드로 안분한 도달 점유율 (= `age_bands`)
메타 5세 구간을 연수 비례로 안분(18-24의 18-19→10대, 20-24→20대 등). 65+는 65-69 60%·70+ 40%로 추정 분할.

| 연령대 | 도달 점유율 | 상태 |
| --- | --- | --- |
| 10-19 | 0.0807 | ✅ 실측(13-17 + 18-19 안분) |
| 20-29 | 0.3171 | ✅ 실측 |
| 30-39 | 0.2763 | ✅ 실측 |
| 40-49 | 0.1679 | ✅ 실측 |
| 50-59 | 0.0968 | ✅ 실측 |
| 60-69 | 0.0496 | ✅ 실측(60-64 + 65-69 추정) |
| 70+ | 0.0116 | ⚠️ 추정(65+ 분할) |

- **10대 발견:** 메타 13-17 도달이 695K뿐(13세 미만 차단·청소년 제한). 18-19가 들어와 10대 점유율은 ~8%. 기존 "침투율 0.80" 추정은 침투율로는 과대였으나 결과 점유율(~8%)은 기존과 비슷.
- `needs_real_values: false` (실측 확정). 남은 추정은 70+(65+ 분할 가정)뿐.

## 4. 정확한 실측 데이터 추출 가이드

추정 구간(10대·50대 이상)을 실측으로 채우는 두 가지 방법. **둘 다 로그인/다운로드가 필요해 AI가 자동 수집 불가 → 사용자 직접 수행.**

### 방법 A — KPF 원본 보고서 (무료, 전체 연령 교차표)
요약 기사엔 20~40대만 있고 50/60대 인스타 수치는 **원본 보고서 PDF의 교차표**에만 있다.

```
한국언론진흥재단(kpf.or.kr)
 → 미디어정보 → 조사분석서 → 수용자조사
 → 「2024 소셜미디어 이용자 조사」 보고서 다운로드(PDF)
 → 본문 "소셜미디어 서비스별 × 연령 교차표"에서 인스타그램 행의 50대·60대·(70대) 칸
```
- 장점: 무료·공신력. 단점: 만 19세+라 10대는 여전히 없음(10대는 오픈서베이 만 15세+ 리포트 보조).

### 방법 B — Meta 광고 관리자 '잠재 도달'(가장 정확) ⭐
"메타가 실제 도달하는 한국 인구"를 연령×지역으로 직접 산출. 이게 있으면 KPF 추정 전부 대체.

```
광고 관리자 → 캠페인 만들기 → 목표 "인지도(Awareness)" 선택  ※ 앱 홍보는 앱 연결 요구라 비추천
 → 광고 세트(Ad set) 단계 → 잠재고객(타깃) 섹션
 → ★ "어드밴티지+ 잠재고객" → "원래 타깃 옵션으로 전환" 클릭(아래 주의)
 → 위치(Locations) = 대한민국
 → 연령(Age) = 최소~최대를 한 구간씩 설정(성별·상세타깃은 비움)
 → 오른쪽 패널 "추산 잠재고객 규모(Estimated audience size)" 숫자 읽기
```
- ★ **어드밴티지+ → 원래 타깃 전환이 필수.** 기본값인 "어드밴티지+ 잠재고객" 모드는 **"최소 연령" 한 칸만** 보여 구간(최소~최대)을 끊을 수 없다. "원래 타깃 옵션으로 전환"을 누르면 확인 팝업이 뜨는데, **"현재 설정 유지"가 아니라 전환(직접 지정)** 쪽을 고르고 확인. 전환 성공 판정 = **연령이 최소·최대 두 드롭다운**으로 바뀜.
- **메타 연령 구간**: 13-17 / 18-24 / 25-34 / 35-44 / 45-54 / 55-64 / 65+ → 우리 밴드(10·20·30대…)로 매핑 필요(연수 비례 안분).
- 각 구간 잠재 규모를 기록 → 전체 합 대비 비율 = 메타 도달 연령 분포. **광고는 게시하지 말 것**(추산만 읽고 종료, 과금 없음).
- 주의: "추산 잠재고객 규모"는 광고 세트의 **잠재고객(위치·연령) 섹션**에 포커스해야 오른쪽에 뜬다. 상단 앱/이름 섹션에선 "캠페인 정보"만 보인다.
- 한계: 메타 최소 연령은 13세(10대 일부만), 상한은 65+ 단일 버킷이라 65-69/70+ 분리 불가.

## 5. 재측정 시 반영 방법 (도달 분포 갱신)

`age_bands`는 **도달 점유율(합≈1)** 이다. 재측정하면

1. 메타 7개 구간 추산치를 §3.2처럼 기록 → 연수 비례로 우리 10년 밴드에 안분 → 합으로 나눠 점유율 산출.
2. `backend/domain/simulation/data/simulation/distributions/meta_reach.json`의 `age_bands`(+`measured_meta_buckets`)를 갱신. `metric_type: reach_share` 유지.
3. `source`·측정일·`caveats` 갱신.
4. 검증: `cd backend && uv run pytest tests/simulation/test_reachability.py -v` + 연령 분포 확인.

> **코드 변경 없이 JSON 값만 바꾸면** 즉시 반영된다(샘플러 `_reach_marginal`가 파일을 읽음). 단 분포(합≈1) 형식 유지 — 침투율(도달÷인구) 넣지 말 것(인구 이중적용).

## 6. 한 문장 요약

**"메타 접근성"은 원래 KISDI(사실상 유튜브)·이후 KPF 침투율로 쟀으나, 메타 추산치가 인구를 초과해 침투율이 깨지므로(>1.0), Meta 광고 관리자 실측 '도달 분포'로 확정하고 샘플러가 이를 연령 marginal로 직접 사용한다(인구비중 곱 제거). 남은 추정은 65+ 분할의 70+뿐.**
