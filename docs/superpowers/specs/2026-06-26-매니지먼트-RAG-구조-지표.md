## 1. 에이전틱 RAG — 요청 한 건의 흐름

```mermaid
flowchart TD
    U([사용자 질문]) --> CLS{의도 분류<br/>LLM gpt-4o-mini}
    CLS -->|ADVISE · 광고 무관| GEM[Gemini CLIO<br/>일반 채팅]
    CLS -->|MANAGE · 광고 도메인| RE[ReAct 에이전트<br/>LangGraph · 최대 5라운드]

    RE --> LIVE[live_* 실측 도구<br/>Meta 숫자 · 환각 금지]
    RE --> SKB[search_kb<br/>하이브리드 검색 벡터+키워드 RRF]
    RE --> ACT[propose_action<br/>운영 변경 '제안만']

    SKB --> CRAG{CRAG-lite<br/>근거 충분한가}
    CRAG -->|충분| ANS
    CRAG -->|부족| RW[쿼리 재작성<br/>재검색 1회]
    RW --> CRAG
    CRAG -->|여전히 부족| WEB[web_search<br/>Tavily · advisory]

    ACT --> HITL{Tier3 위험<br/>돈 늘어남}
    HITL -->|승인 필요| INT[interrupt<br/>사람 승인 대기]
    HITL -->|저위험| ANS

    LIVE --> ANS([답변 + trust 라벨 + 인용])
    WEB --> ANS
    INT -.승인 후.-> EXE[Executor 단일 경로<br/>멱등·감사·Tier 재검증]
    ANS --> FB[👍/👎 피드백 루프]
    ANS --> MEM[(STM thread<br/>+ LTM cross-session)]

    classDef live fill:#d1fae5,stroke:#059669;
    classDef kb fill:#fef3c7,stroke:#d97706;
    classDef act fill:#fee2e2,stroke:#dc2626;
    class LIVE live;
    class SKB,WEB kb;
    class ACT,HITL,INT,EXE act;
```

**핵심 원칙** — 숫자는 실측 도구(`live_*`)에서만, 해석·정책은 KB에서. 운영 변경은 제안만, 실행은 사람 승인 경로(Executor 단일 경로).

## 4. 리소스 절감 — Meta 호출 N+1 제거 (검증됨)

```

지금  ██████                                         6   (상수)
                                                     ── 약 86% ↓
```

### 4-2. 호출 구조 변화

```mermaid
flowchart TB
    subgraph before [그전 · N+1]
        A1[목록·광고세트·자금 3콜] --> A2[캠페인별 maximum N콜]
        A2 --> A3[활성별 today M콜]
```

## 5. 개선 여정 (작업 내역 — 수치 검증은 §3)

> 측정 기반 개선 루프를 돌렸다. 단, **before 시점 결과 파일이 저장되지 않아 개선 델타(before/after %)는 커밋 데이터로 재현되지 않는다.** 검증되는 수치는 §3의 단일 스냅샷 **0.778**뿐이다.

| 단계 | 한 일 | 결과 |
| --- | --- | --- |
| 베이스라인 | 엄격 judge 측정 → 과엄격·행동버그 식별 | 진단 |
| Grounding 게이트 | 시도 → 개선 없음 | **revert** (음성 결과도 결과) |
| judge 재보정 + 라우팅 수정 | 환각 중심 채점 + 개념질문→search_kb·live 덤프 금지 | 적용 |
| 재측정(저장됨) | n=27 · judge×3 | **0.778** ✅ `_faithfulness_results.jsonl` |

**개선 델타를 입증하려면** — before 시점(라우팅 수정 전) 코드로 eval을 한 번 더 돌려 결과 파일을 남기고, 현재(0.778)와 동일 judge·동일 n으로 비교해야 한다. 지금은 단일 스냅샷만 신뢰 가능.
