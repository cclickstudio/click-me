# 매니지먼트(4-2) 테이블 — 목록·역할

> 작성 2026-06-26 · 도메인 `domain/management` · 라이브 Neon 기준(마이그레이션 028 적용 후)
> management 도메인이 쓰는 테이블과 각 역할만 정리한 레퍼런스. 전체 스키마는 `docs/db-schema.md`.

---

## 1. 지식베이스 / RAG (에이전트 근거)

| 테이블 | 역할 |
|---|---|
| `management_kb_documents` | KB 부모 문서(정책·플레이북·KPI·벤치마크). trust(`verified_by`)·버전·출처(`source_url`)·유효기간(`effective_from`/`expires_at`)·`content_hash`(증분 재임베딩 판단) |
| `management_kb_chunks` | 문서를 쪼갠 청크 + `embedding`(pgvector) + `search_vector`(tsvector GIN). **하이브리드 검색(벡터+키워드 RRF)의 실체**. `document_id`로 부모 조인해 trust 전달 |
| `management_kb_eval_cases` | eval 골든셋 — 질문·기대도구(`expected_tools`)·기대인용·기대이상유형. 어시스턴트/진단 품질 측정 입력 |
| `management_kb_feedback` | 👍/👎 피드백 — `rating`·`failure_type`(wrong_tool/stale_doc/…)·`corrected_answer`. 피드백 루프 적재 |

## 2. 채팅 / 에이전트 관측 (어시스턴트)

| 테이블 | 역할 |
|---|---|
| `management_chat_sessions` | 대화 세션 — `thread_id`·tenant/user/project·campaign 스코프 |
| `management_chat_messages` | 메시지 로그 — `role`·`content`·`model`·`tokens_in/out`·`latency_ms` |
| `management_agent_runs` | ReAct run 관측 — `tools_used`·`retrieved_chunks`·`citations`·`steps`·`interrupt_state`·`suggested_action` |
| `management_user_memory` | **장기기억(LTM)** — (tenant, user) 네임스페이스 key-value(`content` jsonb). 세션 넘는 선호·결정 |

> **단기기억(STM)** 은 LangGraph 체크포인터(`checkpoints`·`checkpoint_blobs`·`checkpoint_writes`·`checkpoint_migrations`)가 담당 — thread 상태·HITL 승인 재개용. management 전용 아님(LangGraph 표준 테이블, `management_` 접두사 없음).

## 3. 거버넌스 / 실행 (제안 → 승인 → 실행)

| 테이블 | 역할 |
|---|---|
| `management_audit_events` | append-only 감사 로그 — 제안~실행 전 과정의 `stage`·`outcome`·`category`·`run_id`·`detail`(마스킹). 거버넌스 이력 단일 출처 |
| `management_idempotency_keys` | 멱등키 — approval당 1회 실행 보장(중복 방지), `claimed`·`result`(리플레이) |
| `management_regeneration_jobs` | 크리에이티브 재생성 비동기 잡 — `candidates`·`selection_token`·`proposal`·`status`·`outcome_reason` |

> 제안·승인·실행의 **본 레코드**(`action_proposals`·`approvals`·`execution_runs`)와 에스컬레이션 사다리(`remediation_escalations`)는 **인메모리로만** 동작해 DB 테이블을 두지 않는다(마이그레이션 026에서 미사용 테이블 제거). 영속이 필요해지면 그때 재도입. 감사 흔적은 `management_audit_events`가 담당.

## 4. 외부 연동 / 캠페인

| 테이블 | 역할 |
|---|---|
| `management_meta_connections` | org별 Meta 연결 — `access_token_enc`(**암호화** 저장)·`ad_account_id`·`page_id`·`ig_user_id`·`scopes`·토큰 만료. 멀티테넌시 실연동의 뿌리 |
| `management_created_campaigns` | 앱에서 생성한 캠페인 — `meta_campaign_id`·`objective`·`daily_budget_krw`·`execution_mode`·`deleted_at`(소프트삭제)·`simulation_id`(시뮬 연결) |
| `management_campaign_kpi_overrides` | 캠페인 KPI 수동 보정 — `cvr`·`roas`. 전환추적 미설정 캠페인에 사용자가 직접 넣는 값 |

## 변경 이력 (마이그레이션 026~028, 2026-06-26)

- **026 DROP** — `action_proposals`·`approvals`·`execution_runs`·`remediation_escalations` (ORM 정의만 있고 미사용, 인메모리로 동작)
- **027 DROP** — `audit_logs`·`user_settings`·`rag_chunks`·`generator_kb_chunks`·`chat_long_term_memory`·`chat_brand_profiles` (죽은/orphan 잔재)
- **028 RENAME → `management_`** — `audit_events`·`idempotency_keys`·`regeneration_jobs`·`meta_connections`·`campaign_kpi_overrides`·`created_campaigns` (management 전용 접두사 정합)
