# 이미지 리드 광고 — 업로드 → 자동 분배 게재 + 샘플 시안

> 목표: 프론트에서 이미지 업로드 + 예산·기간 입력 → Meta가 최적 분배(자동 placement, FB/IG)로
> 리드 광고 생성(PAUSED) + 샘플 시안(미리보기) 표시. 전환(리드)으로 CVR·ROAS 실측.

## 결정 (확정)

- **구조** OUTCOME_LEADS → 광고세트(예산·기간, 자동 배치) → 즉석 폼 → 광고(이미지 + SIGN_UP).
- **분배** Meta 자동(placement 미제한). 우리가 FB/IG 수동 설정 안 함 — 이미 자동.
- **안전** 생성은 PAUSED. 실제 게재(과금)는 사용자가 활성화 버튼으로 시작.
- **이미지** Meta `/adimages` 업로드 → image_hash → 소재 link_data.image_hash.
- **시안** Meta `/generatepreviews` → FB 피드 + IG 포맷 HTML iframe.

## 체크리스트

- [ ] 1. client: 멀티파트 이미지 업로드(`post_image`) + 미리보기(`generatepreviews`) 호출
- [ ] 2. writer: `upload_image` → image_hash, `generate_previews` → HTML 목록
- [ ] 3. create_full_campaign·create_ad에 image_hash 연결(이미 파라미터 존재)
- [ ] 4. 스키마: CampaignConfig.image_hash, CreateCampaignRequest.image_hash
- [ ] 5. 엔드포인트: POST /management/ad-image(업로드), POST /management/ad-preview(시안)
- [ ] 6. 프론트: 폼에 이미지 업로드 + 시안(미리보기) 표시, image_hash를 제안에 전달
- [ ] 7. 테스트: 업로드 계약 테스트, create_ad image_hash 첨부 검증

- `/adimages` 응답: `{images: {<filename>: {hash, url}}}` → hash 추출.
- `/generatepreviews`: `creative`(object_story_spec JSON) + `ad_format`(MOBILE_FEED_STANDARD,
  INSTAGRAM_STANDARD) → `{data: [{body: "<iframe…>"}]}`. iframe은 Meta 호스팅.
- 멀티파트는 form data(post)와 달라 client에 별도 메서드 필요(httpx files=).
- 게재(ACTIVE)는 실과금 + 자율 활성화 차단 → 사용자 클릭. 생성·업로드·시안은 무과금.
