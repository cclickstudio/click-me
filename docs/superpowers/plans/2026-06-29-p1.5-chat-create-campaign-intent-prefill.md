# P1.5 — 챗 캠페인 생성 인텐트 + 폼 prefill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 챗에서 "캠페인 만들어줘"류 발화를 하면 **생성 폼 카드가 자동으로 뜨고**(버튼 없이), 발화에서 말한 값(이름·예산·목표)이 **폼에 미리 채워진다**. P1에서 만든 `ChatCreateCampaignCard`를 그대로 쓰고, 인텐트 감지와 prefill 경로만 얹는다.

**Architecture:** B안(가벼움) — 백엔드 `chat.py`의 `/complete` 스트림 맨 앞에 **키워드 1차 필터 → `gpt-4o-mini` 인텐트·파라미터 추출**(기존 `_extract_memory`와 동형) 단계를 추가한다. 생성 의도면 SSE `meta`에 `embed:'create_campaign'` + `prefill`을 실어 내려보내고 오케스트레이터를 우회한다. 프론트는 그 `meta`를 읽어 `ChatCreateCampaignCard`에 `prefill`을 전달, `CampaignForm`은 `initial` prop으로 초기값을 받는다. **오케스트레이터(deep_agent)·정식 엔드포인트·executor는 미수정.**

**Tech Stack:** FastAPI(`chat.py`, OpenAI `gpt-4o-mini`) · Next.js/TS · Tailwind. 백엔드 순수 함수는 pytest로, 프론트는 `pnpm lint`+`pnpm build`+수동.

**상위 설계:** `docs/superpowers/specs/2026-06-29-chat-campaign-actions-reuse-overview-design.md`. **선행:** P1(`2026-06-29-p1-chat-create-campaign-embed.md`) 완료 — `ChatCreateCampaignCard`·embed 렌더·트리거 버튼 존재.

- [ ] **Step 3: 구현** — `chat.py`에 추가. `_extract_memory` 정의 근처(다른 LLM 헬퍼들 사이)에 둔다.

```python
# 캠페인 생성 인텐트 — 키워드 1차 필터로 LLM 호출을 아끼고, 통과 시 gpt-4o-mini로 의도·파라미터 추출.
_CREATE_KW = ("만들", "생성", "런칭", "출시", "새로")


def _looks_like_create(message: str) -> bool:
    """LLM 호출 전 싼 1차 필터 — '캠페인' + 생성 동사 동시 등장 시만 통과."""
    return "캠페인" in message and any(k in message for k in _CREATE_KW)


_CREATE_INTENT_PROMPT = (
    "사용자 메시지가 '새 광고 캠페인을 만들어 달라'는 요청인지 판단하고, 요청이면 언급된 값을 추출하라.\n"
    "- 실제로 생성을 요청(만들어줘/생성해줘/새 캠페인 런칭 등)하면 is_create=true.\n"
    "- 생성 방법 질문('캠페인 어떻게 만들어?')·성과 분석·기타는 is_create=false.\n"
    "- name: 캠페인 이름(언급 시). objective: 'traffic'(클릭) 또는 'leads'(잠재고객·전환).\n"
    "- total_budget_krw: 총 예산을 원 단위 정수로('5만원'=50000, '십만원'=100000). 미언급은 null.\n"
    "- 언급 안 된 필드는 null.\n"
    'JSON만 출력: {{"is_create": bool, "name": "..."|null, '
    '"objective": "traffic"|"leads"|null, "total_budget_krw": 정수|null}}\n\n'
    "[메시지]\n{q}"
)


async def _detect_create_campaign(message: str) -> dict | None:
    """발화가 캠페인 생성 요청이면 prefill dict(없는 키는 생략)를, 아니면 None.

    is_create=true면 추출값이 없어도 {} 를 반환한다(빈 폼이라도 띄운다). 추출 실패·비생성은 None.
    """
    if not _looks_like_create(message):
        return None
    import json as _json  # noqa: PLC0415

    try:
        resp = await _get_clio_client().chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": _CREATE_INTENT_PROMPT.format(q=message[:300])}],
            temperature=0.0,
            max_tokens=120,
            response_format={"type": "json_object"},
        )
        data = _json.loads(resp.choices[0].message.content or "{}")
    except Exception:  # noqa: BLE001 — 추출 실패는 인텐트 없음으로(보수)
        return None
    if not data.get("is_create"):
        return None
    prefill: dict = {}
    if data.get("name"):
        prefill["name"] = str(data["name"])[:80]
    if data.get("objective") in ("traffic", "leads"):
        prefill["objective"] = data["objective"]
    if isinstance(data.get("total_budget_krw"), int) and data["total_budget_krw"] > 0:
        prefill["total_budget_krw"] = data["total_budget_krw"]
    return prefill
```

```python
    async def generate() -> AsyncGenerator[str, None]:
        # 캠페인 생성 인텐트 — "캠페인 만들어줘"류면 생성 폼 카드를 띄우고 종료(오케스트레이터 우회).

        if create_prefill is not None:
            meta = {
                "source": "management",
                "label": "캠페인 생성",
                "engine": "폼",
                "embed": "create_campaign",
                "prefill": create_prefill,
            }
            yield f"data: {json.dumps({'meta': meta}, ensure_ascii=False)}\n\n"
            for piece in _chunks("새 캠페인 생성 폼을 준비했어요. 값을 확인하고 승인해 주세요."):
                yield f"data: {json.dumps({'token': piece}, ensure_ascii=False)}\n\n"
            yield 'data: {"done": true}\n\n'
            return
        # ── 기존 흐름(메모리 회수·오케스트레이터) 계속 ──
        memory_context: str | None = None
```
