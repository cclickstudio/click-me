### 웹검색 시연 (라우팅 민감 — 아래 각본대로)

- **1안(한 방)** — "우리 트래픽 캠페인 실측 CTR이 괜찮은 수준인지 웹에서 최신 자료 찾아서 평가해줘"
  ("업계 평균/벤치마크"를 앞세우면 지식베이스로 오라우팅되므로 **캠페인을 주어로**, 웹은 수단으로만.)
- **2안(2단계, 가장 안전)** — ① "트래픽 캠페인 상세 진단해줘" → ② "이 CTR이 요즘 기준으로 좋은 편이야? 웹에서 최신 근거 찾아서 알려줘"
  (①로 매니지먼트 컨텍스트를 깔고 ②를 이어붙이는 각본. 데모 흐름상으로도 자연스러움.)

### 3군 — HITL 액션 카드 (07-06 ✅ · **데모 직전 스모크 필수**)

| 순서 | 발화 | 임팩트 포인트 |
|---|---|---|
| 8 | 잠재고객 캠페인 일시중지해줘 | 조치 확인 카드(승인 버튼) — 자동 실행 없는 HITL 시연 |
| 9 | 새 캠페인 만들어줘. 이름 여름 프로모션, 목표 트래픽, 예산 5만원 | 슬롯 추출→생성 폼→승인 대기 |

> ⚠ 8·9는 위젯(카드) 기반 — 07-09 확인된 위젯 미표시 증상(§6 #8)이 번졌을 수 있으니 발표 직전 한 번 쳐보고, 카드가 안 뜨면 데모에서 제외.

### 데모에서 피할 발화 (07-09 실측 실패 모드)

- 타깃 설정 보여줘 / 플랫폼·연령성별 분해해줘 / 크리에이티브 보여줘 — 라우팅 오류·타 캠페인 소재 표시(§6 #7)

- 소재 교체 / 내 시뮬 목록 보여줘 — 위젯 미표시(§6 #8)
- "~하고 ~도 해줘" 복합 요청 — 다도구 간헐 실패(§6 #1)

## 6. 발견 / 이슈

| # | 이슈 | 상세 · 개선 |
|---|---|---|
| 1★ | **복합(다도구) 요청 간헐 실패, 단일은 안정** | 한 발화에 여러 도구 요구 시 첫 시도 "응답 오류/생성 불가" 빈발(가벼운 위젯 4개 묶음도 실패). Meta 아닌 **오케스트레이터(gpt-4o-mini) 다도구/콜드 취약**. 단일로 나눠 재시도하면 안정. → 재시도/부분복구·턴 분할·타임아웃 상향 |
| 2 | 무거운 live 도구 콜드 지연 | `weekly_report`·`full_report`·`rebalance`는 캠페인 수만큼 Meta `get_metrics` 순차 호출→첫 호출 느림. 재현 스크립트 직접 호출은 예외 없이 정상(로직 무결). → 병렬화(rate-limit 주의) 또는 타임아웃 상향 |
| 3 | 상세류 얼버무림 응답 | detail·targeting 질문에 "곧 정리…"만 내는 경우(구 #9). 도구는 실행됨(배지). → 프롬프트 개선 |
| 4 | 리밸런싱 1개 조정 실발화 미확인 | 새 로직 채팅 정상("제안 없음"). 1개 증액/감액은 활성 캠페인 있는 org라야 확인 가능(데모 모두 종료) |

| 6 | 이름 추천 채팅 미연결 | UI 시뮬 집행 폼 전용. 원하면 `create_campaign`에 시뮬 맥락 시 배선 가능 |

## 7. 결론

- 매니지먼트 핵심 기능(목록·예산·주간/전체 리포트·리밸런싱·이상·시뮬 대비·상담·소재교체·메모리·캠페인 생성·조치) + **KB·Tavily 근거보강**이 채팅에서 도달·실행됨을 근거 배지로 확인(신규 `live_full_report`·`consult_anomaly`·`replace_creative`는 재실행 확인 대상).
- 실 캠페인 조회는 성과비교 화면과 동일한 **전체 지표**로 통일, 종료 캠페인은 **전체 누적 리포트**로 커버.
- 연결점(before/after·create_campaign·replace_creative·recall_history·run_improvement·성과비교→시뮬결과)과 APScheduler 자동화가 채팅/UI 레이어에 살아 있음.
- 백엔드 로직·데이터 결함 없음(도구 직접 호출 전수 확인). 남은 개선은 **LLM 라우팅 안정화**(§6 #1·#7)와 **위젯 파이프라인**(§6 #8, 공통부 조율), 무거운 도구 콜드 지연.
- 발표 시연은 **§3-1 데모 추천 세트**(안정 7 + 조건부 2 + 웹검색 각본)를 따른다.
