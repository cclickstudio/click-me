# 제너레이터 모델 선택 전략

광고 생성 파이프라인의 모델을 프로바이더 교체 가능하게 설계해, `.env` 변경만으로
OpenAI 외 모델(향후 회사 자체 모델 포함)로 확장할 수 있도록 한다.

## 텍스트 모델 (분석·전략·템플릿·카피·QA·설명)

- 모든 텍스트 노드는 `domain/generator/llm/factory.py`의 `build_text_llm(temperature)`를 통해 모델을 받는다.
- 노드가 직접 `ChatOpenAI`를 생성하지 않으므로, 모델 교체 지점이 한 곳으로 모인다.

| 변수 | 의미 | 예시 |
| --- | --- | --- |
| `GENERATOR_TEXT_PROVIDER` | 프로바이더 | `openai`, `anthropic`, `google_genai` |
| `GENERATOR_TEXT_MODEL` | 모델명 | `gpt-4.1` |
| `GENERATOR_TEXT_BASE_URL` | OpenAI-호환 엔드포인트(선택) | 회사 내부 게이트웨이 URL |

동작:
- `provider=openai` → `ChatOpenAI`. `GENERATOR_TEXT_BASE_URL`이 있으면 `base_url`로 분기(회사 OpenAI-호환 모델).
- 그 외 → LangChain `init_chat_model(model, model_provider=...)` 범용 초기화. 해당 통합 패키지(`langchain-anthropic`, `langchain-google-genai` 등)가 설치돼 있어야 한다.
- 모든 텍스트 노드는 `.with_structured_output(...)`를 쓰므로, 선택 모델은 structured output(function calling)을 지원해야 한다.

주의:
- reasoning 모델(o3/o4-mini 등)은 `temperature`를 받지 않아 현재 노드와 비호환. 사용하려면 노드의 temperature 인자를 제거해야 한다.

## 이미지 모델 (광고 후보 이미지)

- `image_generator.py`의 `generate_image()`가 `GENERATOR_IMAGE_PROVIDER` 기준으로 분기한다.
- `openai`(gpt-image-1 등)와 `google_genai`를 지원. 그 외 값은 `NotImplementedError`로 명확히 실패시킨다.
- `google_genai`는 모델명으로 한 번 더 갈린다 — `imagen-` 접두사면 Imagen(`generate_images`/`predict`), 그 외(`gemini-*-image*`)는 Gemini 네이티브 이미지 생성(`generate_content`, `response_modalities=["IMAGE"]`). 두 API는 입출력 형식이 달라 어댑터 함수가 분리돼 있다(`_generate_with_gemini_native` / `_generate_with_imagen`).
- `GENERATOR_IMAGE_QUALITY`는 OpenAI 전용(`low`/`medium`/`high`) — Gemini·Imagen 둘 다 해당 개념이 없어 무시된다. 대신 `AdSize`를 `aspect_ratio`로 매핑해 전달하는데, Gemini 네이티브는 `1:1`/`3:2`/`2:3`, Imagen은 지원 비율이 달라(`1:1`/`3:4`/`4:3`/`9:16`/`16:9`) 가장 가까운 값(`1:1`/`4:3`/`3:4`)으로 매핑한다.
- 새 이미지 프로바이더는 `_generate_with_openai`와 같은 어댑터 함수를 추가하고 `generate_image()`의 디스패치에 등록한다.

| 변수 | 의미 | 예시 |
| --- | --- | --- |
| `GENERATOR_IMAGE_PROVIDER` | 프로바이더 | `openai` / `google_genai` |
| `GENERATOR_IMAGE_MODEL` | 모델명 | `gpt-image-1` / `gemini-3-pro-image` / `imagen-4.0-ultra-generate-001` |
| `GENERATOR_IMAGE_QUALITY` | 품질(openai 전용) | `low` / `medium` / `high` |

## 회사 자체 모델 연동 경로

- **OpenAI-호환 API**(가장 쉬움): `GENERATOR_TEXT_PROVIDER=openai` + `GENERATOR_TEXT_BASE_URL=<게이트웨이>`.
- **LangChain 통합 존재**: 해당 패키지 설치 후 `GENERATOR_TEXT_PROVIDER=<provider>`.
- **완전 자체 프로토콜**: `factory.py`에 분기를 추가하고 `BaseChatModel` 구현/래퍼를 연결.
