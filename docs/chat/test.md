# ClickMe 수동 테스트 가이드 (시뮬레이터 + 채팅)

> 도연님이 **직접 손으로** 모든 기능을 순서대로 체험·점검하는 시나리오. 위에서 아래로 따라가면 됩니다.
> 각 단계는 **무엇을 → 어떻게(입력/클릭) → 이렇게 나와야 함 → 안 되면 의심**으로 구성. 입력 예시는 그대로 복붙해도 됩니다.
> "이렇게 나와야 함"과 다르면 → 그 자리에서 멈추고 메모(스크린샷 + 브라우저 콘솔 F12). 빈 값·멈춘 스피너·`[object Object]` 같은 건 절대 그냥 넘기지 마세요.

---

## 0. 사전 준비 (한 번만)

1. **백엔드 기동** — 터미널에서:
   ```
   cd backend && uv run dev.py
   ```
   `Application startup complete` 또는 8000 응답이 뜰 때까지 대기(처음엔 langchain 로딩으로 30초~1분).
2. **프론트 기동** — 다른 터미널에서:
   ```
   cd frontend && pnpm dev
   ```
   → 브라우저에서 `http://localhost:3000`.
3. **DB 확인(중요)** — 개인 DB(`ep-soft-band-…`)인지:
   ```
   cd backend && uv run python -c "from core.config import settings;import re;print(re.search(r'@([^/]+)/',settings.database_url).group(1))"
   ```
   `ep-spring-wind-…`(팀 DB)면 멈추고 `.env` 고치기.
4. **테스트 계정** (개인 DB 전용·평문):

   | 역할 | ID | PW | 비고 |
   | --- | --- | --- | --- |
   | 어드민(ADMIN) | `admin` | `admin1234` | 관리자 화면 |
   | 컴퍼니(COMPANY) | `yohan` | `yohan1234` | 조직 화면 |
   | 유저(USER) | `doyeon` | `fjdksla0852` | 프로젝트 "건도연" 보유 |

> 💡 시뮬은 실제 LLM 호출이라 1회 ~1분, 제너(이미지 생성)는 ~1~2분·실비용이 듭니다. 급하면 소비자수를 작게(30) 두세요.

## 1. 로그인 & 역할별 화면 (3계정)

각 계정으로 로그인해 화면 차이를 확인합니다. (`/sign-in`)

- **admin / admin1234** → 로그인 → 좌측 메뉴에 관리자 화면(`/admin/*`) 접근 가능, 일반 화면도 정상.
- **yohan / yohan1234** → 조직/컴퍼니 화면(`내 조직` 등) 접근, **관리자 전용은 안 보이거나 차단**.
- **doyeon / fjdksla0852** → 일반 화면 + 프로젝트 "건도연" + `채팅` 정상, 관리자 전용 차단.

> 이렇게 나와야 함 — 세 계정 모두 로그인 성공, 역할에 없는 메뉴는 안 뜨거나 들어가면 막힘.
> 안 되면 의심 — 로그인 후 흰 화면/무한 로딩, 권한 없는 메뉴가 다 보임(게이팅 실패).

**이후 2~8번은 `doyeon` 계정으로 진행**합니다(프로젝트가 있어 흐름이 완전함).

## 2. 채팅 기본

좌측 메뉴 `채팅` 클릭 → `/chat`.

1. **새 채팅 시작** — 빈 화면에 퀵 칩(🧪 시뮬 돌리기 / 🎨 시안 만들기 / 📊 비교하기 / ❓ 도움말 등)이 보임.
2. **일반 메시지 전송** — 입력창에 그대로:
   > 안녕, 너는 뭘 도와줄 수 있어?
   - 이렇게 나와야 함 — 답이 **글자 단위로 흐르며(스트리밍)** 끊김 없이 완성. 전송 중엔 다시 못 보냄.
3. **슬래시 메뉴** — 입력창에 `/`만 입력 → 명령어 드롭다운(자동완성)이 뜨는지. `/시` 입력 시 `/시뮬레이션`·`/시뮬목록`·`/시안목록`으로 필터.
4. **줄바꿈** — `Shift + Enter`로 줄바꿈, `Enter`로 전송. 한글 입력 중(조합 중) Enter가 **오전송되지 않는지**.
5. **빈 메시지** — 아무것도 안 쓰고 Enter/전송 → **안 보내져야 함**.
6. **세션 사이드바** — 메시지를 보내면 왼쪽에 세션이 생기고 **제목이 자동으로** 대화 요약으로 바뀌는지(예: "광고 어시스턴트 소개"). "새 채팅" 그대로면 메모(F13 미동작 의심).
7. **세션 새로고침** — 브라우저 새로고침(F5) → 방금 대화·위젯이 **그대로 복원**되는지.

> 안 되면 의심 — 스트리밍이 통째로 한 번에 뜨거나 중간에 끊김 / 새로고침하면 대화가 사라짐 / 콘솔(F12)에 빨간 에러.

## 3. 시뮬레이터 — 채팅에서 (핵심 흐름)

1. 빈 채팅에서 **🧪 시뮬 돌리기** 클릭 (또는 `/시뮬레이션` 입력).
2. 입력 위젯이 단계별로 뜸. 예시값:
   - **제품명**: `클릭미 수분크림`
   - **광고 설명**: `24시간 보습, 끈적임 없는 수분크림. 건성 피부 진정에 특화.`
   - **카테고리 / 광고 목표**: `화장품 / 구매 전환`
   - **가상 소비자 수**: `30` (빠르게) 또는 `50`
3. **엣지 체크** — 중간에 제품명을 비우거나 공백만 넣어보기 → **"다음"이 비활성**이어야 함(그냥 넘어가지면 버그).
4. 마지막 단계에서 **실행** → 로딩 스피너.
5. **끝까지 기다리기** (수십 초) → **4대 KPI** 결과 위젯:
   - 클릭 의향률(신뢰구간), 구매의도(1~5 평균+분포), 신뢰도(1~5), 거부율(+사유)
   - 이렇게 나와야 함 — 네 KPI가 **실제 숫자 + 구간/분포**로 채워짐. `"예측 CTR 5%"` 같은 단정·"-"·빈칸이면 메모.
6. **토론 자동 시작** → AI 소비자들 발언이 실시간으로 흐름 → 끝나면 **"토론 요약 보기"** → 요약 위젯.
7. **개선 제안** — 토론 후 "개선 시안 만들기" 같은 수락 카드(Approval)가 뜨는지.
8. **진행 중 새로고침 체험** — (가능하면) 다시 한 번 시뮬 실행 후 **도는 도중에 F5** → 스피너/진행이 **복원**되는지.
9. **완료 후 새로고침** — F5 → 결과·토론·요약 위젯이 **다 복원**되는지.

> 안 되면 의심 — 스피너만 계속 돌고 결과 안 나옴 / KPI가 비어있거나 0 / 토론이 결과보다 한참 늦거나 안 뜸 / 새로고침하면 결과가 날아감.

## 4. 시뮬레이터 — 전용 페이지 (`/simulation`)

채팅 위젯 말고 전용 페이지에서도 같은 게 되는지.

1. 좌측 `광고 시뮬레이션` → `/simulation`.
2. **2단 카테고리 셀렉트**(업종 대분류 → 세부 류) + **광고 목표 칩**(+기타 직접입력) + **인구 생성**(성별/세그먼트/표본 수) 입력.
   - 예: 대분류 `화장품/뷰티` → 세부 류 선택 / 목표 `구매 전환` / 표본 `50`.
3. 실행 → 결과 페이지에서 KPI·분포·세그먼트(OCEAN) 반영 확인.
4. 결과 상세(`/simulation/[id]`) 진입·새로고침 복원.

> 이렇게 나와야 함 — 채팅 위젯과 동일한 품질의 결과. 전용 페이지가 더 자세한 분포/세그먼트를 보여줄 수 있음.

## 5. 제너레이터 — 시안 만들기 ⚠️(시간·비용)

> 이미지 실제 생성이라 ~1~2분·비용 발생. 1~2회만.

1. 빈 채팅에서 **🎨 시안 만들기** (또는 `/제너레이터`).
2. 입력(4단계):
   - **상품명**: `클릭미 콜드브루`
   - **상품 설명**: `고산지대 원두로 내린 산미 강한 싱글오리진 콜드브루`
   - **타깃 고객**: `30대 직장인 커피 애호가`
   - **광고 목표**: `conversion` (기본값 그대로 둬도 됨)
   - **저장할 프로젝트**: `건도연`
3. **엣지 체크** — 상품명을 비우면 → 마지막 "광고 생성 실행"이 **비활성 + "필수 항목을 입력해주세요: 상품명…" 안내**가 떠야 함(G5). 그냥 실행되면 버그.
4. **광고 생성 실행** → 진행 스피너(클릭하면 전체화면 진행).
5. **끝까지 기다리기** (~1~2분) → **시안 3개**(헤드라인·전략) + 이미지. "상세 보기"로 `/generations/[id]`.
6. **생성 직후 화면 주시** — 결과가 뜨는 순간 입력 폼이 **잠깐 빈 폼(1/4)으로 깜빡이지 않는지**(G6 글리치 — 깜빡이면 메모). 새로고침하면 정상인지.
7. **새로고침 복원** — F5 → 생성 결과 위젯이 그대로.

> 안 되면 의심 — "0개 생성 완료" / 이미지 안 뜸 / 에러인데 성공처럼 표시 / 생성 직후 빈 폼 깜빡임.

**에러 체험(선택)** — 일부러 실패 유발: 브라우저 개발자도구 → Network → `Offline` 켜고 실행 → **에러 카드 + "다시 시도"**가 떠야 함(흰 화면/무반응이면 버그). 끝나면 Offline 끄기.

## 6. 비교 / A/B / 배치

1. **`/비교`** — 시뮬을 2개 이상 돌린 뒤 입력. 두 시뮬의 4대 KPI를 나란히 + 델타.
2. **`/배치` 또는 `/AB`** — 광고 2개를 동시에 비교 시뮬레이션하는 입력 위젯(batch).
   - 예: 광고A `여름 한정 30% 할인` / 광고B `첫 구매 무료배송` 식으로 두 카피를 넣고 실행.
3. 결과에서 어느 쪽이 KPI가 높은지 비교가 보이는지.

> 참고 — "동일 패널 공정 비교 + 통계적 승자 판정"(AB 태스크)은 아직 구현 중일 수 있음. 비교 위젯이 뜨고 두 시안 KPI가 나란히 보이면 현 단계로는 정상.

## 7. 메모리 / RAG / 용어 질문

1. **용어 질문(CLIO RAG)** — 채팅에 그대로:
   > ROAS가 뭐야?
   > AISAS가 뭔지 설명해줘
   > 클릭 의향률은 어떻게 보는 거야?
   - 이렇게 나와야 함 — 정의 설명 + (있으면) **근거/인용 칩**.
2. **전략 질문** — `/추천` 또는:
   > 20대 여성 타깃 화장품인데 어떤 플랫폼이랑 전략이 좋아?
3. **롱텀 메모리** — 위에서 시뮬/제너를 "클릭미 수분크림", "콜드브루"로 돌린 뒤, **명시 안 하고**:
   > 우리 제품에 맞는 카피 톤 추천해줘
   - 이렇게 나와야 함 — 앞서 입력한 브랜드/제품군(수분크림·콜드브루)을 **기억한 듯한** 답. 전혀 모르면 메모(롱텀 메모리 미반영).

> 안 되면 의심 — 용어 질문에 엉뚱한 답/근거 없음 / "ROAS"를 모른다고 함.

## 8. 슬래시 명령 전체 1회씩

입력창에 하나씩 넣어 각각 동작 확인 (`/`만 치면 목록 자동완성).

| 명령 | 기대 동작 |
| --- | --- |
| `/시뮬레이션` | 시뮬 입력 위젯 |
| `/제너레이터` | 광고 생성 입력 위젯 |
| `/배치` (별칭 `/AB`) | 광고 2개 동시 비교 시뮬 위젯 |
| `/리포트` | 시뮬·생성 성과 PDF 리포트 |
| `/시뮬목록` | 최근 시뮬레이션 목록 |
| `/시안목록` | 최근 생성 시안 목록 |
| `/분석` | 과거 성과 종합 요약 |
| `/추천` | 목표·예산 입력 → 전략·플랫폼 추천 |
| `/비교` | 시뮬 2개 KPI 나란히 비교 |
| `/키워드` | SNS 해시태그·키워드 추천 |
| `/도움말` | 명령어·예시 안내 |

> 이렇게 나와야 함 — 각 명령이 해당 위젯/응답으로 연결. 잘못된 입력에도 흰 화면 없이 안내.

**리포트(PDF) 체험** — `/리포트` 또는 시뮬 결과의 리포트 버튼 → PDF 다운로드 → 열어서 **KPI·근거가 실제로 담겨** 있는지. 콜드(새 세션에서 바로) 진입 시에도 저장된 리포트로 재조립되는지.

## 9. 권한 / 게이팅 (다시 3계정)

1. `doyeon`(USER)으로 로그인한 상태에서 **남의 프로젝트/조직 데이터**가 안 보이는지(자기 "건도연"만).
2. 로그아웃 상태(토큰 없음)로 `/chat` 직접 URL 진입 → 로그인으로 **튕기는지**.
3. `yohan`(COMPANY)·`admin`으로도 채팅이 각자 정상 동작하는지(역할별 데이터 차이 메모).

> 안 되면 의심 — 로그아웃인데 채팅이 열림 / 남의 프로젝트가 보임 / 403인데 흰 화면.

## 10. 영속성·엣지 종합 체크 (놓치기 쉬운 것)

- [ ] 시뮬/제너 **완료 후 새로고침** → 결과 위젯 복원
- [ ] 시뮬/제너 **진행 중 새로고침** → 스피너/진행 복원
- [ ] 세션 목록에서 다른 세션 갔다 와도 메시지 유지
- [ ] **동시 실행** — 시뮬 도는 중에 또 시뮬/제너 시도 → **"이미 진행 중" 차단**, 끝나면 다시 가능
- [ ] 아주 긴 메시지·특수문자(`<script>`, 이모지 등) 입력 → 깨지지 않고 정상 처리
- [ ] 전 과정에서 브라우저 콘솔(F12)에 **빨간 에러 0개**

## 버그 메모 양식 (발견 시)

```
[제목] 한 줄 요약
[심각도] 막힘 / 심각 / 보통 / 사소
[재현] 1) … 2) … 3) …
[기대] 이렇게 나와야 함
[실제] 실제로 이렇게 됨
[증거] 스크린샷 / 콘솔 에러 / Network 응답
```

> 이 파일은 사람이 직접 도는 체험용입니다. 자동 QA(꼼꼼한 전수 검증)는 tasklist의 **C4** 명세로 루프가 수행합니다.
