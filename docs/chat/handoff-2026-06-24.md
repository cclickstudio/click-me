## 2. 제너레이터 채팅 연동 (★ 핵심 미검증 — 자세히)

### 2-1. 현재 상태: "옛 패턴"이라 시뮬과 다름
제너레이터는 **내가 시뮬에 적용한 새 파이프라인으로 아직 안 바꿈**. `GenFormWidget.tsx`는 리팩토링 전 `SimFormWidget`과 같은 옛 구조다.

- 파일: `frontend/src/components/chat/GenFormWidget.tsx`
- 4단계 폼: 상품명* → 상품설명* → 타깃* → (광고목표 + **저장 프로젝트 선택\***).
- 실행: `api.generator.start({product_name, product_description, target_audience, campaign_objective, project_id, product_image_temp_key})` → `generation_id`
- 진행: `api.generator.stream(generation_id)` SSE(pct/message) → completed/error
- 완료 `finish(gid)`: `api.generator.detail(gid)` → **위젯 안에 후보 인라인 표시** + `onResult('[생성결과] 광고 시안 N개 생성 완료', {kind:'gen', id})` 호출.
- done 화면: 후보 3개 미리보기 + "상세 보기 →" `/generations/{genId}`.

### 2-2. 제너레이터가 트리거되는 2가지 경로
1. **직접**: 채팅 "🎨 시안 만들기" 칩 / "광고 시안 만들어줘" → `/api/chat/complete` → 오케스트레이터 `generator_node`(action=run) → `gen_form` 위젯 내려줌(질문에서 product_* 추출해 초기값 채움).
2. **개선 루프(시뮬·토론 후)**: 토론 완료 → `DebateStreamWidget`의 `ApprovalWidget(run_generator)` 수락 → `handleApprove('run_generator')` → `POST /api/chat/approve`(loop_count+1) → 오케스트레이터가 "개선 시안 만들어줘" 질문으로 `generator_node` → `gen_form` 위젯.
   - ※ 이 경로는 시뮬 파이프라인 리팩토링(개선 제안을 토론 후로 이동) 이후 **한 번도 브라우저로 안 돌려봄**. 최우선 테스트.

### 2-3. 옛 패턴이라 생기는 불일치(= 손볼 거리)
시뮬은 이렇게 바꿨는데 제너레이터는 안 됨:
- **`[생성결과]` 텍스트를 아직 직접 보냄**(시뮬은 제거함). → `onResult`→`handleSend('[생성결과]…')`→`gen_result_node`가 "새 시안으로 재시뮬" approval 제안(`rerun_simulation`). 이 흐름이 의도대로인지 확인 필요.
- **입력 요약/결과 위젯 분리 없음**(시뮬은 `sim_input`+`sim_result`로 분리). 제너레이터는 위젯 안에 결과 인라인.
- **새로고침 시 폼으로 리셋**(결과 위젯 영속화 없음). 단 사용자 메시지의 `msg.result`(resultRef)는 영속화돼서 "생성 결과 보기" 버튼은 새로고침 후에도 남음(`/generations/{id}`로 이동).
- **완료 후 입력 폼 숨김 처리 없음**(시뮬은 sim_result 있으면 gen_form 숨김).

### 2-4. dev 머지로 제너레이터 백엔드가 많이 바뀜 (재검증 필수)
머지로 들어온 변경(우리가 만든 건 아님, 하지만 채팅에서 제너레이터 돌리면 같이 탐):
- `domain/generator/pipeline/image_providers.py`(신규)·`image_generator.py`·`multimodal_generator.py`·`graph/nodes/candidate_gen.py`·`strategy.py` 등.
- 즉 **이미지 생성 경로가 바뀌었을 수 있음** → 채팅에서 생성 돌렸을 때 끝까지 도는지, 후보 이미지가 나오는지 실제로 확인해야 함.
- 이미지 생성은 외부 모델(기획서상 GPT Image 2 / Gemini Omni) 키·비용 의존 → 키 없거나 한도면 실패/빈 후보 가능. 실패 시 에러 메시지·폴백 확인.
