## 0. 동시에 돌릴 수 있나? → 네, 됩니다 (조건 2개)

1. **브랜치 분리** — 집=`feat/chat-doyeon`, 학원=`feat/chat-backend`(집 브랜치에서 분기). 같은 브랜치에 양쪽이 push하면 non-fast-forward 충돌. **브랜치를 가르면 push 충돌 0.**
2. **파일 분리(프론트/백)** — 집=`frontend/`만, 학원=`backend/`만. 만지는 파일이 안 겹치면 나중 머지가 깨끗함.
3. 유일한 공유 파일 `docs/chat/tasklist-2026-06-24.md`는 **학원이 건드리지 않음**. 학원은 진행상황을 `docs/chat/academy-progress.md`(신규)에만 기록. 집이 최종 머지 때 본 태스크리스트에 반영.

## 2. 충돌 방지 규칙 (양쪽 공통)
- 자기 디렉터리(`frontend/` vs `backend/`)만 수정. 경계 넘지 말 것.
- **공유부 주의**: `core/models.py`는 학원이 R4-1에서 **신규 모델 클래스만 append**(기존 컬럼 변경 금지). `api/main.py` 라우터 등록은 **append-only 한 줄**.
- 학원은 `docs/chat/tasklist-2026-06-24.md`를 **수정 금지**. 진행 로그는 `docs/chat/academy-progress.md`에만.
- 커밋은 자주, 한 태스크 1커밋. push는 **각자 자기 브랜치만**(`--force` 금지, main 금지).
