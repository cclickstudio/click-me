## 발견 결함 (심각도 정렬)

### S1 — chat API 전면 무인증/무소유권 (Broken Access Control / IDOR)
- **심각도**: S1 (보안). 단 CLAUDE.md "인증 현재 UI만·JWT 미적용·점진 도입" 페이즈와 연관(완전한 신규 결함은 아니나, 현재 게이팅 갭을 정확히 명시).
- **재현**: 토큰/인증 헤더 **없이** `GET http://localhost:8001/api/chat/sessions/988b68f7-.../messages` 호출 → **200 OK + 전체 메시지 본문 반환**.
- **원인**: `api/routers/chat.py` 전 엔드포인트가 `current_user`/`get_current_user`를 **0회** 사용. `delete_session(session_id, db)`·`get_session_messages(session_id, db)` 등이 세션 소유자 검증 없이 `session_id`만으로 동작(`domain/chat/history.py:543` delete_session도 소유자 미확인). 라우터 등록(`api/main.py:124`)에도 `dependencies=[]` 없음.
- **영향**: 세션 ID만 알면 **타 사용자/타 조직의 채팅 내역 조회·삭제 가능**. Task E(타 리소스 403 차단)는 서버측에서 전면 미충족. 프론트는 토큰 없으면 UI 리다이렉트로 가리지만 API는 무방비.
- **증거**: PowerShell `Invoke-WebRequest` 무헤더 200 응답(본문 메시지 포함).

### S2 — 한글 IME 조합 중 Enter 오전송 (isComposing 미가드)
- **심각도**: S2. 모든 한글 사용자가 다중 음절 입력 후 Enter로 조합 확정 시 영향.
- **재현**: textarea에 한글 입력 후 `isComposing=true`인 Enter keydown 디스패치 → 메시지가 **전송됨**(textarea 비워지고 메시지 추가). 정상이라면 조합 확정 Enter는 전송하지 않아야 함.
- **원인**: `ChatConversation.tsx` onKeyDown(~1699·~1713)이 `e.key==='Enter' && !e.shiftKey`만 검사하고 **`e.nativeEvent.isComposing`(또는 keyCode 229)를 확인하지 않음**.
- **수정안**: Enter 분기에 `&& !e.nativeEvent.isComposing` 가드 추가(한 줄). 단 핵심 입력 로직이라 리포트만 하고 미수정.

### S3 — 채팅 세션 하드 삭제 + 무확인(데이터 손실 위험)
- **심각도**: S3(데이터 손실 관점 S2 소지).
- **재현**: 사이드바 휴지통 아이콘 원클릭 → 확인 다이얼로그 없이 즉시 삭제. `domain/chat/history.py:551 db.delete(session)` + FK CASCADE로 메시지 영구 삭제(소프트삭제/휴지통 복원 경로 없음).
- **영향**: 오클릭 시 채팅 영구 소실. (프로젝트/시뮬엔 /trash 소프트삭제가 있으나 채팅 세션엔 없음 — 일관성 결여.)

#### S3 — sim_result 위젯 로딩 지연 시 "…" 장시간 표시 (로딩/실패 미구분)

- **재현**: 채팅에서 생성 실행(1~2분 대기) → 완료 시 백엔드는 성공("새 시안이 준비됐네요" + 재시뮬 제안 노출, DB에 후보 3개 영속)인데, 채팅에 **gen_result 위젯(후보 이미지)이 안 뜨고 gen_form이 빈 "1/4 상품명"으로 재출현**(이미지 0개). **페이지 새로고침 후에야** gen_result(후보 3개 이미지·헤드라인) 정상 표시·빈 폼 사라짐.
- **영향**: 사용자는 1~2분 기다린 생성 결과를 즉시 못 보고 빈 폼만 봄 → 결과 유실로 오인(리로드 유도 안내 없음).
- **원인 추정**: `ChatConversation`의 gen_form 숨김 조건(뒤 메시지에 gen_result 존재 시 숨김)이 라이브 렌더에서 제때 적용 안 됨 + GenFormWidget이 완료 후 자체 상태를 step1로 리셋. 영속은 정상(리로드 시 복원).
